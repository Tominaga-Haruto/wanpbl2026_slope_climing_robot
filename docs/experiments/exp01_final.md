## 付録: 指示書との差分（全部で 6 点）

1. **`terrain_type=plane` が使えなかった。** `TerrainImporter.import_ground_plane` は
   `GroundPlaneCfg` のデフォルト usd_path（S3 の `Isaac/5.1/Isaac/Environments/Grid/default_environment.usd`）を
   必ず引きに行き、`FileNotFoundError: Unable to open the usd file` で落ちる。
   URL 自体は HTTP 200 で到達可能なので Omniverse 側の resolver の問題。このパスは importer 内に
   ハードコードされていて cfg から差し替えられない。
   → `terrain_type=generator` のまま `sub_terrains` の proportion を flat=1.0 / 他すべて 0.0 に
   上書きして「全面平地」を作った。ローカル生成・ネット不要で物理的には平面と同じ。
   ラン B・C_flatonly・measure_crab.py のすべてでこの方式。

2. **自作 `feet_air_time_positive_biped` の引数が Isaac Lab 同梱版と違う**（`threshold` ではなく
   `threshold_min` / `threshold_max`）。自作側を使い `threshold_min=0.0, threshold_max=0.4` とした。
   reward は常に非負なので `reward *= reward > 0.0` は何も削らず、同梱版 `threshold=0.4` と数値的に等価。
   weight は G1 と同じ 0.25。

3. **weight 0.0 の報酬項は RewardManager が加算処理ごとスキップする**（`reward_manager.py:145-148`、
   関数自体が呼ばれない）。よって `feet_air_time_biped` を weight=0.0 で足したラン A の挙動は完全に不変。

4. **トルク飽和率は actuator 側の effort_limit から計算した。** `robot.data.joint_effort_limits`（sim 側）は
   1e9 で、DelayedPDActuator は explicit actuator なのでクリップは actuator 内で行われる。
   実際に使った上限は HR 24 / HAA 30 / HFE,KFE 30 / FFE 20 N·m。

5. **Isaac Lab の実体は `D:\Tominaga\IsaacLab`**（editable install の参照先、`train.py` の
   skyentific import パッチ入り）。`D:\IsaacLab` も存在するが別物なので読んでいない。
   また headless 起動には環境変数 `OMNI_KIT_ACCEPT_EULA=YES` が必須で、無いと EULA プロンプトの
   入力待ちで `Unable to bootstrap inner kit kernel: EOF when reading a line` で落ちる。

6. **`play.py --video` は未確認。** 学習 2 本が GPU を占有している間に描画を伴う起動を試すのは
   避けた。setup_log.md にある「TeamViewer 経由では GPU 描画デバイス列挙不可」の制約もあるため、
   本体ディスプレイで別途確認するのが早いと思われる。
