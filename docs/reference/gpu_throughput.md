# 4096 env の基準値（RTX 3090 Ti 24GB / i7 Ultra 7 265K / Windows 11）

VRAM の数値はデスクトップ描画ぶん（約 4.3 GB）を含む GPU 全体の使用量。

| 並走本数 | 構成 | 秒/iter | it/s | 合計 it/s | VRAM | 温度 | GPU util |
|---|---|---|---|---|---|---|---|
| 1本 | A のみ（起動直後の ETA から） | 約 2.2 | 0.45 | 0.45 | 8.1 GB | 54 °C | — |
| 2本 | A | 4.00 | 0.250 | **0.528** | 13.2 GB | 61 °C | 94 % |
| 2本 | B | 3.60 | 0.278 | | | | |
| 3本 | A | 6.00 | 0.167 | **0.556** | 17.6 GB | 61 °C | 97 % |
| 3本 | B | 5.14 | 0.194 | | | | |
| 3本 | B2 | 5.14 | 0.194 | | | | |

（2本・3本とも 180 秒の iter 数から実測）

## B2 の判定

- 起動条件: VRAM 13.2 GB ≤ 16 GB、温度 61 °C ≤ 80 °C → **満たしたので起動した**。
- スループット判定: 3本合計 0.556 it/s は 2本合計 0.528 it/s の **+5.2 %** で、基準の +10 % に届かない。
- さらに A が 4.00 → 6.00 秒/iter（+50 %）と大きく遅くなり、iter 1600 到達が約 1 時間遅れる。
- → 規定どおり **B2 は停止**（05:38）。A と B の 2 本で継続。

B2 の run フォルダは 30 iter 強で止めたもの。評価対象外。
