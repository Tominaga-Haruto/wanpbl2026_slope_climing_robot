## 状況（これだけ分かっていればよい）

- 0x1C（LL_HR、AK10-9）は D9-2 で4回とも動かなかったが、**原因はMIT経路ではなく試験の要求角**だった。`電流 = 指令Kp × 位置誤差` が実測で確定している（傾き 8.20 / 8.31 A/rad、指令Kp 7.937、比 1.03 / 1.05）。
- したがって **不感帯 = 動き出し電流 ÷ 指令Kp**（Kt 不要）。0.66 A で動かない 0x1C の不感帯は 4.8°以上。D9-2 の要求角 4.52° / 2.5° では、裸の AK80-9（動き出し 0.63 A）でも動かない。
- D9-3 は要求角 −6.5°＝最大 0.90 A。0.66 A の 1.4倍で、裸の AK80-9 の動き出しも超える。**Kp・Kd・トルク欄・電流中止 1.0 A は変えていない。**
- 送信器 build `D9_BREAKAWAY_20260922_2130`。`stall_guard` により、すでに静止が実証された電流以下しか掛けられない実行は MITフレームを1つも出さずに中止する。Kp 7.937 では 6.86° で電流中止に当たるので、**この方式で探れるのはそこまで**。
- 根拠: `../../reports/2026-09-22_d9-0x1c-current-vs-error.md`。手順: `../../procedures/d9_3_1軸ブレークアウェイ_実験手順.md`。

## 事前に決めた判定

| | 条件 | 結論 | 次 |
|---|---|---|---|
| **A** | 移動 ≥ 3.25° | 普通のスティクション。0x1Cは正常 | 動き出し電流と不感帯を報告書へ。片脚へ進む前にこの不感帯で方策が成立するか判断 |
| **B** | 0.1° ≤ 移動 < 3.25° | 動き出した。異常ではない | Aと同じ。**再試行しない**（値は取れている） |
| **C** | 移動 < 0.1° かつ `TORQUE PATH: verified` | 0.90 A でも動かない＝機構の異常に確定 | 主電源OFF → 機構修正。ゲインを上げない。直らなければ 0x1C を外して単体測定 |
| **D** | `TORQUE PATH` が `absent` / `anomalous` | 前提が崩れている | 主電源OFF → 電気・通信側へ戻る。機構を触らない |
