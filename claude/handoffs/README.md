# 引き継ぎの置き方

```
handoffs/
  active/     いま有効な引き継ぎ（CONTEXT.md が名指しするもの、並行中のもの）
  inactive/   役目を終えた引き継ぎ（読まない。履歴としてだけ残す）
```

- ファイル名は **`YYYY-MM-DD_内容がわかる名前.md`**。`ACTIVE.md` のような中身の分からない固定名は使わない。
- **いま有効な1本は `../CONTEXT.md` の冒頭が名指しする。** `active/` には並行中のものも含めて複数あってよい。
- **終わった引き継ぎは、終わったと判断したエージェントがその場で `git mv handoffs/active/<名前>.md handoffs/inactive/` する。** ユーザーに頼まない。同じ commit で `CONTEXT.md` の名指しとリンクを直す。
- 消さない。`inactive/` に移すだけ。
- `active/` の中の相対リンクは2階層上がる（`../../reports/...`、`../../CONTEXT.md`）。
- 2026-09-23 以前の `chats/`・`reports/` には移動前のパス（`handoffs/<名前>.md`）が残っている。ファイル名で `active/` か `inactive/` を探せばよい。

## 中身（これだけ）

目的と最初の仕事 / 事前に決めた判定 / 許可・禁止 / 並行できること / 記録先。
長い経緯・生ログ・古い仮説は書かない。`../reports/` と `../chats/` に置いて、必要なら1行で参照する。

## 更新のしかた

- **`CONTEXT.md` と引き継ぎ書は書き換える**（現在地が2つあると事故になる）。ただし全文を打ち直すのが高くつくときは、**末尾に日付つきの追記でよい**。その場合は冒頭に「最新は末尾の追記」と1行書く。
- `reports/` と `chats/` は追記のみ。過去の記述を書き換えない。
