# 引き継ぎ運用

`handoffs/ACTIVE.md`だけが次のClaude Code/Codexセッションの開始点である。古い引き継ぎは`chats/`に残し、削除・移動しない。

1. 実測または調査を終えたら、まず`reports/`に根拠・結論・生ログの絶対パスを残す。
2. 優先作業・安全境界・最小読書セットが変わったら`ACTIVE.md`を置換更新する。
3. 全体の優先順位や成果物の場所が変わったら`../CONTEXT.md`も更新する。
4. この三つを同じ対象限定commitで`main`へpushする。

ACTIVEには、目的と完了条件、確認済みの事実、最小読書セット、許可／禁止事項、実行環境と記録先だけを書く。長い経緯・生ログの転記・古い仮説は`reports/`または`chats/`へ置く。
