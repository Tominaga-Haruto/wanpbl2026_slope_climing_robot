- **`--policy-slew-dps D`（0 < D ≤ 60）**: 方策段階で**全10軸**の送信目標を D °/s に制限。起点は ramp の固定目標。`--arm --all-axes` の方策 run では**必須**（無いと拒否）。1軸 run・`--hold-pose` では使えない（1軸 run の挙動は不変）。
