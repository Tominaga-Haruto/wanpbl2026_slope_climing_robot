# D11: Jetson・無線プロコンによる平地デプロイ実験手順

> 構成は **Switch 2 Pro（Bluetooth）→ Jetson GPU → T265・USB2CAN×2 → ロボット** である。WRS PCとWindowsノートPCはD11の制御経路に入らない。Jetsonの`ver9_jetson_deploy.py`が50 Hzで42次元観測、GPU ONNX推論、10軸MIT送信を行う。
>
> `--arm`を付けない限りCANは送信しない。通電後の終了・例外・T265異常・CAN異常・無線コントローラー読み取り失敗では、全10軸へ零MITフレームを3回送る。非常停止は主電源OFFであり、ソフト停止では代替しない。

## 0. D11の実装済み範囲

- JetsonのGPU ONNX Runtime（TensorRTまたはCUDA）を必須にした方策推論。CPUへフォールバックした場合はアームを拒否する。
- 左スティック前後=`vx`、左右=`vy`、A=`+wz`、Y=`-wz`。前進は`+vx`、右は`-vy`で、A/Y同時押しは`wz=0`。いずれも学習時範囲`[-1,+1]`内に制限する。
- 左右5軸のUSB2CANを別チャネルとして同時に使用する。既定は左`0`・右`1`だが、Jetsonでの列挙順を受信確認で必ず照合してから指定する。
- T265が200 msより古い、CANフィードバックが古い・`err!=0`、電流・速度の既存上限超過、コントローラーのイベントデバイス消失・読取失敗、例外のいずれでも停止経路へ入る。

## 1. Jetsonへ置く成果物

Jetsonの`/home/wan-pbl-2026/robot_deploy`へ、次のソースを同じ階層でコピーする。重みをGitへ入れない。

- `ver9_jetson_deploy.py`
- `jetson_deploy_preflight.py`
- `ver9_d8_sender.py`、`ver9_integration.py`、`ver9_shell.py`
- `policy_integration.py`、`policy_dry_run.py`、`motor_console_ver8_2.py`、`cubemars.py`
- `H_eff13p5_2999`のデプロイパッケージ一式（`policy.onnx`、manifest、golden、契約、表）

成果物をコピーした後、Jetsonで`python3 -m py_compile`を用いて上記のPythonファイルを構文確認する。CAN、T265、モーター電源はこの時点で接続しない。

## 2. 無通電の必須受入

1. Bluetoothでプロコンを接続し、`Uniq=98:b6:e9:4a:87:92`から当日の`eventN`を取得する。`eventN`を固定値としてコードや手順へ保存しない。
2. JetsonにT265と2本のUSB2CANを接続する。ただしロボット主電源はOFFのままにする。
3. `jetson_deploy_preflight.py`で、当日の`eventN`、Hデプロイパッケージ、GPU ONNXプロバイダを確認する。`providers`に`TensorrtExecutionProvider`または`CUDAExecutionProvider`が表示されなければ不合格である。CPU実行へ妥協しない。
4. `ver9_jetson_deploy.py --preview`で、10ID、AK80-9のKp=28.571/Kd=2.867、AK80-9 FFEのKp=19.048/Kd=2.867、操作対応を確認する。プレビューはCANを送信しない。
5. 各USB2CANに受信専用で接続し、左脚5IDと右脚5IDが意図したchannelに現れることを確認する。D7と異なる列挙なら、`--left-can-channel`と`--right-can-channel`へ実測値を渡す。ID・配線を推測で入れ替えない。

この5項目のうち一つでも不合格なら、D11を始めない。

## 3. 開始条件

- [ ] D9とD10が合格し、D10後に姿勢、部品、配線、T265取付けを変えていない。
- [ ] §2が合格し、Jetson上の実行コードとHデプロイパッケージのSHA256を記録した。
- [ ] 主電源遮断担当者、操作者、記録担当者を分けた。遮断担当者は常に主電源に手が届く。
- [ ] 床は平坦・乾燥・滑りにくく、進行方向と左右に停止余地を含む空間がある。人、物、USB・電源ケーブルは入れない。
- [ ] 動画は開始前から、機体全体、足元、主電源担当、ケーブル余長が分かる角度で連続撮影する。

異音、転倒傾向、接触、ケーブルの張り、`err`、例外、プロコン切断があれば、PCを見る前に主電源をOFFにする。

## 4. 段階0: 中立操作で2秒

1. 主電源ON後、PCを操作せず3秒間観察する。
2. プロコンの左スティックを離し、A/Yを離した中立でアームする。中立でなければ実行器はアームを拒否する。
3. 全指令上限を`vx=0`、`vy=0`、`wz=0`にし、2秒だけ実行する。
4. 終了直後に主電源をOFFにする。CSVに50 Hzの指令と10軸目標角が残ることを確認する。

姿勢変化、例外、`err`、異音、接触、干渉がなければ合格。それ以外はD11を終了する。

## 5. 段階1: 前進を操作する

段階0合格後だけ実行する。最初は`max-vx=0.05`、`max-vy=0`、`max-wz=0`で開始し、プロコン前入力を最大2秒だけ行う。中立へ戻したとき`vx=0`へ戻ること、D10と同じ前方へ進もうとすることを確認する。異常なら主電源をOFFにして終了する。

## 6. 段階2: 横移動と旋回を一変数ずつ解放する

段階1に合格して初めて、横移動を`max-vy=0.05`、次に旋回を`max-wz=0.05`として、それぞれ最大2秒で単独確認する。一度に`vx`、`vy`、`wz`を増やさない。H_eff13p5はその場旋回の合格方策ではないため、`vx=vy=0`でA/Yを押す試験はしない。
