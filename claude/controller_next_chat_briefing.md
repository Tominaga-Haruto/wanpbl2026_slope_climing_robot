# Jetson コントローラー次チャットへの指示書（2026-09-18）

## ゴール

Jetsonに有線接続済みのSwitch 2 Proを、**モーター/CAN/ONNXへ接続せず**に50 Hzで読み、左スティックから画面・ログだけに `(vx, vy, 0)` を出す `pad_probe.py` を作る。

## 確定した実測

- Jetson: Linux 5.10.216-tegra / aarch64。
- 入力は `Microsoft X-Box 360 pad`、USB ID `045e:028e`。
- 安定入力パス: `/dev/input/by-id/usb-045e_XBOX_360_For_Windows_000000000001-event-joystick`。`event2` は現時点の番号であり、コードに固定しない。
- 左スティック: `ABS_X` (0)、`ABS_Y` (1)、範囲 -32768〜32767。中立は概ね X=0 / Y=-1。
- A: `BTN_SOUTH` (304)、Y: `BTN_WEST` (308)。今回は使わない。
- 仮デプロイは左スティックだけの並進。A/Y旋回は、旋回方策を別途用意してから乾式試験する。

## 最初に確認すること

Jetsonのターミナルで、まず以下を実行して出力を確認する。パッケージを入れたり、既存のモーター制御コードを編集したりしない。

```bash
pwd
python3 --version
python3 -c "import evdev; print(evdev.__version__)"
ls -l /dev/input/by-id/usb-045e_XBOX_360_For_Windows_000000000001-event-joystick
```

- `evdev` が無い場合は、勝手に導入しない。Jetsonで使う専用venvとインストール方針を先に決める。
- プロジェクトの実体がJetsonにあるか、既存のCAN制御プログラムとはどのプロセス境界でつなぐかを確認する。

## `pad_probe.py` の要件

- `evdev`で安定パスを読む。CAN、`can` モジュール、ONNX、モーター制御コードはimportしない。
- 50 Hzで標準出力とCSVへ時刻・生のX/Y・正規化値・`(vx, vy, 0)`・状態を出す。
- デッドゾーンは最初は0.05以上にし、実測ログで調整する。
- `ABS_Y` の前後符号と `ABS_X` の左右符号は、方策のbase座標契約を確認してから決める。推測で確定しない。
- スティックを離したら必ず `(0, 0, 0)`。指令上限は画面上の仮値として `vx ±0.3`、`vy ±0.2` を超えない。
- 入力切断・読取例外・200 msの無イベントは状態 `timeout` に遷移し、出力は `(0, 0, 0)` を維持する。
- 本番の非常停止は物理的なモーター電源遮断を手元に置く。今回の乾式プログラムにCAN送信や解除機能を加えない。

## 乾式テストの順序

1. 中立を10秒置いてCSVを確認する。
2. 左スティックを前後左右へ短く倒し、出力だけを確認する。
3. USBを抜き、200 ms以内に `timeout` とゼロ指令になることをログで確認する。
4. 再接続時に勝手に非ゼロへ戻らないことを確認する。

## 禁止事項

- モーター通電、CAN送信、ONNX推論、T265との統合。
- 右スティック、十字キー、トリガー、肩ボタン、HOMEを本番操作に割り当てること。
- モデル、重み、生ログをGitへ追加すること。
