## 2. 分かった事実

1. **AK 3.0 はサーボと MIT の区別がない。** CAN を「定期フィードバック」か「問い合わせ応答」に設定する（公式FAQ）。→ ver6 で「MIT 専用応答が来ない」のは仕様どおり。
2. **定期フィードバックは 1〜500 Hz で設定可能。** 50 Hz は工場設定で上限ではない（上位機で変更）。→ 「制御周期の上限 50 Hz」は**設定で外せる可能性**。
3. **上位機に「CAN 通信途絶時の設定」がある。** → A4（指令が途切れたとき）は測るだけでなく**設定で決められる可能性**。
4. **AK80-9 V3.0 のエンコーダは内側（ロータ側）磁気式 16bit の単一。** 公式FAQ「原点を電源断後も覚えさせるにはデュアルエンコーダ品が要る」。
   → **恒久原点（A3）が3回とも失敗したのと整合。** 減速比 9 なので、電源投入時の出力軸角は **40 deg（360/9）ごとの取り違え**が起こりうる。デプロイでは「毎回、決まった姿勢（治具）で原点を取る」前提になる見込み。
5. **レンジは資料の版で違う。** AK80-9 の速度: V1.0.15 ±50 / V3.0.0 ±30 / ver6 採用 ±65（出典不明、V3.2 の可能性）。AK10-9 のトルク: ±65（旧）/ ±54（V3.0.0）。
   **ファームと送る側でレンジが違うと、その比で値が縮んで読まれる。** 公式の CAN 例（ID 0x68）は ±12.5 / ±50 / ±65 の旧 AK10-9 レンジで書かれている。
6. MIT の位置原点とサーボ原点の関係、MIT の位置が多回転か、指令途絶時の挙動は **どの資料にも書かれていない**（v3.0.0 / V1.0.15）。→ 実測するしかない（ver7）。
7. データシート Kt = 0.095 N·m/A（ロータ側）× 9 = **0.855**（出力軸）。実測の「指令トルク/電流 = 0.59」とは 0.69 倍違う。定格 9 N·m / ピーク 22 N·m / 無負荷 570 rpm / バックラッシュ 15 arcmin / 定格 48 V。

## 3. 立てた仮説と ver7 の検証コマンド

| 仮説 | 根拠 | ver7 | 判定の読み方 |
|---|---|---|---|
| **H1: ver6 の「実効Kd = 0.48」は、速度レンジのずれ（65 と 30 の比 0.46）が混ざった値** | 資料 V3.0.0 は ±30。0.48 ≈ 30/65 | `vscale` | `r_v`（ファームが読む速度/送った速度）が 0.46 なら ±30、0.77 なら ±50、1.0 なら ±65。`c_d` が Kd そのものの倍率 |
| H2: MIT 位置 = サーボ角 + 定数（倍率1） | — | `morg` を角度を変えて2〜3回 → `ofit` | offset のばらつき < 1 deg なら定数。傾きが出たら倍率（位置レンジ ±12.5 か単位違い） |
| H3: `o 0`（モード5）は MIT の原点を動かさない | ver6 の事故から推測 | `ocheck` | A/B のどちらに近いか |
| H4: 電源を入れ直すと原点が 40 deg 単位でずれる | 単一ロータエンコーダ | 電源再投入 → `overify` | 残差が 40 の倍数に近いと表示される |
| H5: 実効Kp/指令Kp ≠ 1 | Kd に係数があった | `kpscale` | 同じトルクを Kp×δ とトルク指令で出して電流比。**Kt に依存しない** |
| H6: 指令が途切れるとモーターは一定時間で脱力する | ver6 落とし穴3「単発指令だと保護で止まる」 | `wdog` | 静止摩擦以下のトルクで、送信だけ止めて電流を見る。ケーブルを抜かない |
| — | 制御ループ設計 | `lat` / `jit` | 指令→フィードバック遅れ、Windows の 50Hz 周期の揺れ |

## 4. ver7 で直した ver6 の隠れた誤差

- **速度0・トルク0 の欄は 12bit の真ん中に乗らず半LSB 負に読まれる。** AK80-9（±65）で Kd=1 なら常に −0.016 N·m。
  `morg` の小さい Kp（0.24）では**原点が 3〜4 deg ずれる**（シムで再現、Kp=0.24 と 0.98 で結果が食い違った）。→ 0 の欄だけ 2047/2048 を交互に送る。
- `morg` は電流の符号を最初に実測してから寄せる。1LSB の Kp で段階的に寄せ、Kp 0.24 → 0.98 の2段で直線を当て、2段が 3 deg 以上食い違えば不採用。
- 軸が惰性で回っている間は測定を始めない（止まるまで待つ）。
- 全送受信を CSV に自動保存（`logs\\v7_日付\\`）、結果は `mit_calib.json` に ID ごと。
