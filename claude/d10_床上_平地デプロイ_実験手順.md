# D10: 床上・平地 初回デプロイ実験手順

> 対象PCは Windows ノートPC、対象コードは `C:\Users\harut\Connect2USB2CAN\ver9_d8_sender.py`。D9の吊り試験に合格した**同じ最終構成**を、床上で初めて方策に従わせる。実行中に異音、転倒、接触、配線の張り、警告、例外が一つでも起きたら、PC操作より先に主電源をOFFにする。ソフトウェア停止は非常停止の代わりにならない。

## 0. このD10で行うこと・行わないこと

行うことは、T265、両CANの10軸フィードバック、H_eff13p5@2999 のONNX方策、MIT位置指令を50 Hzでつなぎ、平地で短時間の**固定速度指令**を入れることだけである。

現在の送信器が受け取れる速度入力は `--vx` / `--vy` / `--wz` の固定値だけである。Bluetoothコントローラーの実デバイス読取はこの送信器へ未接続であり、D10中にコントローラーを接続・使用しない。コントローラー化はD10の結果を見てから別途実装・乾式確認する。

各実行は最大5秒に制限されている。今回の各段階は2秒で終え、終了・例外時には送信器が10軸へ零ゲインMITフレームを3回送る。その後も主電源をOFFにしてから機体へ近づく。

## 1. D10へ進んでよい条件

下記が全て満たせない場合、床へ下ろさずD10を始めない。

- [ ] D9で、吊り支持中の10軸フィードバックが全数・`err=0`・新鮮な状態で取得できた。
- [ ] D9で、この送信器の `--arm` 実行時に全10軸が意図しない方向・角度へ動かず、異音・支持ずれ・ケーブル干渉・例外が無かった。
- [ ] D9のCSV、コンソール出力、動画を保存し、D9の結果を合格と判断した。
- [ ] D7後に姿勢、部品、配線、T265取付けを変更していない。変更した場合はD7からやり直す。
- [ ] 床は平坦・乾燥・滑りにくく、進行方向2 m以上、左右1 m以上に人・物・ケーブルがない。
- [ ] 主電源の遮断担当者が、実行中ずっと主電源に手を届かせられる。PC担当と分けられるなら分ける。
- [ ] T265、ch=0/ch=1を公開するUSB2CAN V3.3 1台、全モーター電源のケーブルに余長があり、脚・床・人へ接触しない。

## 2. 通電前の準備

1. 主電源をOFFにする。
2. D9の吊り具を外し、機体を平らな床の開始位置へ静かに置く。脚を持ち上げて落としたり、関節を押して姿勢を変えない。
3. 正面・左右側面・上面を撮影する。開始位置と前方の空き領域も写す。
4. 機体を手で支えず、床上で安定していることを確認する。立位を保てない、足裏が浮く、ケーブルが張る場合は中止する。
5. ノートPCでPowerShellを開く。まだ通電も送信もしない。

**ノートPCのPowerShellで実行する。これはCANを送信しない。**

```powershell
cd C:\Users\harut\Connect2USB2CAN
.venv310\Scripts\python.exe ver9_d8_sender.py --preview
```

10行のIDが `13, 1C, 1B, 11, 2A, 21, 12, 1A, 22, 2B` であることを確認する。AK80-9の表示は HFE で `Kp=28.571 Kd=2.867`、FFE で `Kp=19.048 Kd=2.867` でなければ中止する。

## 3. 段階0: 床上・ゼロ速度で2秒

1. 電源遮断担当者の位置を確認してから主電源をONにする。
2. PCを操作せず3秒間、機体・床・ケーブルを観察する。異常があれば主電源をOFFにする。
3. 数秒待ち、両CANの10軸フィードバックが定期的に到着するまで送信しない。
4. 次の1行だけを実行する。

```powershell
.venv310\Scripts\python.exe ver9_d8_sender.py --arm --package C:\Users\harut\wanpbl2026_slope_climing_robot\H_eff13p5_2999\H_eff13p5_2999 --duration 2 --csv logs\d10_00_stand.csv --vx 0 --vy 0 --wz 0
```

5. 2秒間、機体の姿勢・足裏・配線だけを見る。脚へ手を出さない。
6. PowerShellへ戻ったら主電源をOFFにする。CSVが存在することを確認する。

```powershell
Test-Path C:\Users\harut\Connect2USB2CAN\logs\d10_00_stand.csv
```

`True`、例外なし、転倒なし、予期しない大きな関節運動なし、異音なし、ケーブル干渉なしを全て満たすときだけ次へ進む。それ以外はD10を終了する。

## 4. 段階1: ごく小さい前進指令で2秒

段階0に合格したときだけ実行する。前進の正方向はHの `+x` であり、今回の値は学習時範囲 `[-1, +1]` 内の `+0.05` である。

1. 主電源OFFのまま、開始位置へ戻して床・ケーブル・支持者の位置を再確認する。
2. 主電源をONにし、3秒観察する。
3. 次の1行だけを実行する。

```powershell
.venv310\Scripts\python.exe ver9_d8_sender.py --arm --package C:\Users\harut\wanpbl2026_slope_climing_robot\H_eff13p5_2999\H_eff13p5_2999 --duration 2 --csv logs\d10_01_vx_p005.csv --vx 0.05 --vy 0 --wz 0
```

4. 直進しようとする方向、足の接地、姿勢、配線を動画で記録する。横移動、後退、旋回、足の引っ掛かり、転倒傾向、異音、例外のいずれかがあれば主電源をOFFにして終了する。
5. 正常終了後も主電源をOFFにし、CSVの存在を確認する。

```powershell
Test-Path C:\Users\harut\Connect2USB2CAN\logs\d10_01_vx_p005.csv
```

## 5. 段階2: 小さい前進指令で2秒

段階1が「意図した前方へ進もうとし、転倒傾向・異常・例外なし」で合格した場合だけ実行する。段階1が不合格なら、`+0.10` へ上げずD10を終了する。

```powershell
.venv310\Scripts\python.exe ver9_d8_sender.py --arm --package C:\Users\harut\wanpbl2026_slope_climing_robot\H_eff13p5_2999\H_eff13p5_2999 --duration 2 --csv logs\d10_02_vx_p010.csv --vx 0.10 --vy 0 --wz 0
```

終了直後に主電源をOFFにし、CSVを残す。今回の初回D10ではこれ以上の指令値、横移動、旋回、連続実行、コントローラー接続へ進まない。

## 6. 合格判定と記録

今回のD10は、段階0〜2の各2秒を安全に終え、`+vx` で予期した前方への運動傾向が確認できたら合格候補とする。歩行距離、速度追従率、長時間安定、横移動、旋回、コントローラー操作は今回の合格条件ではない。


## 7. 不合格時の境界

不合格時は、指令値を変えたり、同じ条件を連続再試行したり、コードを書き換えたりしない。主電源OFF後にCSV、画面、動画、D7/D9後に変えたものの有無を確認し、原因を切り分けてから次の実験を設計する。
