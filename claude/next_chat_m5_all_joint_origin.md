# 次チャット指示書: 全10関節の原点設定（M5）

## 今回の目的

ロボットを**吊るか寝かせて、脚をまっすぐにした基準姿勢**で、全10モーターへ `o 0` を送る。これは軸を動かさず、現在のMIT/サーボ角を原点に登録する作業である。

基準姿勢で `o 0` を打った後は、H方策のH角とMIT角が同じ座標になる。Hの実際の開始姿勢は、HR/HAA=0、HFE/FFE=-0.1745 rad、KFE=+0.3491 radであり、これは原点設定後に目標角として表す。今回、方策・位置指令は送らない。

## 実施のタイミング

**次チャットの最初に実機へ `o 0` を送らない。** まず部品取外しを伴う単体モーター実験、配線変更、機体の組立てを終える。M5の実際の原点設定は、構成をデプロイ試験用に固定した後、最初の位置指令試験（1モーター）の直前に実施する。

原点設定前でも、ID・機種・H順の設定ファイル作成、ver9の停止設計、`mit_sim`、T265取付け、コントローラー乾式試験は進めてよい。原点を打った後に部品を外したり軸を動かしたりしたら、デプロイ用の原点はやり直す。

## 実行範囲と安全条件

- 実行する前に、機体を吊るか寝かせて機械的に支持する。手で支えるだけなら実施しない。
- 非常停止は主電源OFF。異音、支持ずれ、`err!=0`、フィードバック欠落で即終了する。
- `o 0` は軸を動かさない。
- 今回は禁止: `morg`、`overify`、`jog`、`hold`、`step`、トルク指令、方策送信。
- 起動は `C:\Users\harut\Connect2USB2CAN` で `py -3.13 motor_console_ver8.py`。`python` は使わない。

## 実施手順

最終構成を固定した直後に、`全関節原点設定_実験手順.md` の手順を先頭から最後まで使う。特に、全IDの `s` → `o 0` → `s` は1行ずつ実施する。全軸の原点設定後は `q` で終了し、画面ログと基準姿勢の写真・寸法を残す。

## 今回の完了条件

1. 10台のID・機種・H順・符号が上表どおり記録されている。
2. 基準姿勢を次回も再現できるよう、写真・支持点・寸法を残した。
3. 各IDについて `o 0` 前後の `s` が画面ログにあり、`err=0`。
4. 電源断後は原点が残ると仮定せず、同じ基準姿勢で再設定する運用を記録した。
