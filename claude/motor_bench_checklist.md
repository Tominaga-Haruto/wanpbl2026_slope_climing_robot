## 使い方の要点
 
- 起動: `cd C:\Users\harut\Connect2USB2CAN` → **`py -3.13 motor_console_ver8.py`**（`python` は 3.10 本体を指すので使わない。練習は `--sim`）
- **モーター電源を入れた直後の数秒はフィードバックが来ない。** 「状態なし」なら数秒待って `q` → 起動し直す。
- `log on` で画面を記録。**全指令の送受信は `logs\v7_日付\` に CSV で自動保存**、結果の数字は `mit_calib.json`。
- 指令はすべて「指定秒だけ 50Hz で送って自動停止」。終了時に零指令。
- `x` ソフト停止 / `q` 停止して切断。**本当の非常停止は電源を切ること。**
- ⚠ **フィードバックの電流は大きさだけ信用する。**
- ⚠ **Kp は 0.06 未満だと 0 に潰れる。Kp>0 で Kd=0 にしない。**
- ⚠ **指令を止めてもモーターは最後のトルクを出し続ける（A4）。**
- ⚠ **「スクリプトの再起動」と「モーター電源の入れ直し」は別物。**
- ⚠ **バスが落ちたら電源OFF → USB2CAN 抜き差し → 電源ON。**
- ⚠ **`id` の直後に必ず `model`（AK10-9 はトルク 3 倍）。**
