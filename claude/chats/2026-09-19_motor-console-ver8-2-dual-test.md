# 2026-09-19 motor_console_ver8_2 二機同時試験

## やったこと

- `Connect2USB2CAN/motor_console_ver8_2.py` を、現行 `motor_console_ver8.py` のMITパッカーを使う派生版として追加した。
- 対象を上位機16進の `0x22`（ID34, AK80-9）と `0x12`（ID18, AK10-9）に固定した。各周期では `0x822`、`0x812` の順に送る。
- 実機へは明示的な `--live --confirm-safe-setup` がない限り送らない。実行終了・中止時は両軸へ零MIT指令を10周期送る。
- 実機は動かさず、`py -3.13 -m py_compile motor_console_ver8_2.py` と dry-run を通した。

## 実験手順

### 事前条件

1. 二軸を、相互干渉しない安全姿勢にする。吊り・可動域・配線・電源OFFによる非常停止を確認する。
2. モーター電源投入直後は数秒待ち、`motor_console_ver8.py` で両方の定期フィードバック、`err=0`、静止を確認する。IDは10進で指定する（`id 34` / `id 18`）。
3. その安全姿勢で各軸を `o 0` にする。`o 0` は軸を動かさず、サーボ角とMIT位置の基準を同時にゼロにする。これは原点姿勢を決める本番の置換ではなく、この短い二機試験の共通基準に限る。

### 段階1: CAN未接続の確認

```powershell
cd C:\Users\harut\Connect2USB2CAN
py -3.13 motor_console_ver8_2.py --dry-run --pos22 0 --pos12 0 --seconds 2
```

表示で、ID0x22がAK80-9、ID0x12がAK10-9、送信先が `0x822 → 0x812`、目標が両方0 radであることを確認する。

### 段階2: 二機同時のゼロ位置保持

```powershell
cd C:\Users\harut\Connect2USB2CAN
py -3.13 motor_console_ver8_2.py --live --confirm-safe-setup --pos22 0 --pos12 0 --seconds 2
```

- この段階は目標0 radを両軸へ同じ50 Hz周期で送る。二軸が `o 0` を打った安全姿勢にいるなら、大きな位置移動を指示しない。
- 自動中止は、フィードバック途絶0.30秒超、`err!=0`、電流絶対値1.0 A超、速度100 deg/s超、開始位置から8 deg超の移動。
- 異音、指令していない動き、温度の急上昇があれば、スクリプトの結果を待たず電源OFFにする。

### 段階3: 小さい同時移動（段階2が無中止の場合だけ）

- 目標値は関節の正方向と機械的な余裕を確認した上で、操作者が決める。コードは符号・安全角度を推測しない。
- `--pos22` と `--pos12` を、両方とも基準姿勢から ±0.20 rad以内で指定する。最初は2秒・Kp 1.0・Kd 0.5の固定上限を変えない。
- 完了後、`logs\\dual_v8_2_YYYYMMDD\\dual_HHMMSS.csv` の中止の有無、両IDのフィードバック、各tickの `skew_ms` を保存する。CANは1本なので二フレームは完全同時ではなく直列だが、この値が実測の送信差である。

## 決めたこと・分かったこと

- 二機を同時に制御することはデプロイ前に必要な段階であり、このプログラムはその最小試験である。
- ID34とID18は機種が異なるため、生のMITフレームを共有せず、各機種のver8パッカーで個別に生成する。
- 位置の符号と安全な移動先は記録済みの二IDだけでは決められないため、コード・手順とも推測しない。
