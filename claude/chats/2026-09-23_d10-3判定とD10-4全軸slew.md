# 2026-09-23 D10-3 の判定と D10-4 の準備（Cowork、2往復）

## 入力
- D10-3 の R0×2・R1・R1（足閉じ）・R2・R3・R4 を回した。本人所見: R1 は少し足が閉じた、R3・R4 は左足が後ろ・右足が前に交差してやさしくゆっくり動いた。
- 2往復目で: 全 run で脚を手で軽く支えていた（足が閉じないように、動き出しは任せる）。最後の vx 0.4 の run は遊びで、CSV は無視してよい。画面ログ全文。

## 判定（保存CSVの `--analyze` と画面ログ）
- R1・R2 の hold は 3 s 完走、保持 ≤0.10 A（判定2）。手の支えがあるので確定ではない。
- R3/R4 は ramp 完走後、方策 1〜2 tick 目に電流中止（0x22 4.30 A／0x1A 4.35 A）。原因は、方策段階の slew が 0x1C だけに掛かっていたこと（送信器 1093〜1100 行）。
- D10-2 報告の「1.0 A が自重より小さい」を訂正（報告書冒頭に1行）。

## 決めたこと・実装
- 送信器 build `D10_4_ALLSLEW_20260923_1200`: `--policy-slew-dps`（全軸、`--all-axes` の方策 run で必須）、全軸プレアーム・ゲート（|目標|>40° / |delta|>30°）、`POLICY STAGE`・`SLEW GAP` の表示、`--analyze` の asked 修正。テスト 83本 OK。
- 次は D10-4: 手を離して hold を取り直し → slew 20 °/s・vx 0 → slew 30 °/s・vx 0.2。床上はまだ。
