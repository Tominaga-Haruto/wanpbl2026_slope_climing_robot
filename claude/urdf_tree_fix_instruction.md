## 再利用できる技術（他の場面で使える）

本文書の中で、以下はそのまま有効な手法として残す価値がある。

### ① 順運動学（FK）による「幾何が保たれたか」の検証

URDF を書き換えたとき、**ゼロ姿勢での全リンクのワールド座標を書き換え前後で出して 1e-9 以内で一致するか**を見れば、
「構造だけ変えて形は変えていない」ことを機械的に確認できる。

- FK は base をルートに、各 joint の origin（xyz + rpy）を掛け合わせるだけ（関節角はすべて 0）
- **URDF の rpy は外因性 XYZ（固定軸）**、すなわち `R = Rz(yaw) @ Ry(pitch) @ Rx(roll)`
- scipy なら `Rotation.from_euler('xyz', [r,p,y])` / `as_euler('xyz')`（**小文字＝外因性**）

### ② 親を付け替えても幾何が保たれる理由

URDF では子リンクのフレーム＝ joint フレーム。**親を付け替えても、origin を「新しい親から見た同じ絶対位置」に置き直せば、子リンク以下のフレームはワールドで1mmも動かない。**
4x4 同次変換行列で `A⁻¹ · D` のように計算し、結果を `xyz`（並進）と `rpy`（外因性 XYZ）に戻して書き戻す。`axis` は変更しない。

### ③ リンクの左右判定

**`*_ffe` と `*_haa` のワールド y 座標の符号**で判定する。
`*_hr` は機体中央付近にあり符号が曖昧になりうるので、判定には使わない。
