## 2. ★ 持続時間に規則性は無い（旧記述の訂正）

**旧版は「冷やすほど長く持つ＝熱依存」と書いていた。これは誤り。**

| 直前の休止時間 | 持った時間 |
|---|---|
| 2日（完全に冷えていた） | **約3分** |
| 直後の再投入 | **数秒**（起動ループ） |
| 15分＋完全放電 | **十数分** |

**2日冷やして3分、15分冷やして十数分。冷却時間と持続時間が逆転している。** 熱モデルは棄却。

**→ 規則性が見えない＝間欠故障。** 接触不良か電源系が濃厚だが、**LEDコードが出ず、ケースも開けていないので、これ以上は絞れていない。**

## 3. ★ ドライバ原因説の見立て（2026-09-14 に更新）

**旧版は「ドライバは無関係」と断定していた。これは言い過ぎだった。** 症状を2つに分けて扱う。

|---|---|---|
| **電源が落ちる** | **ほぼ 0%** | 起動ループは **Ubuntu が読み込まれる前**に起きている。存在しないドライバは電源を切れない。落ちたときの負荷も `grep` 程度だった |

## 7. Step 2 — ★ 費用ゼロで試せる4つ（全部未実施）

### A. 保証を確認する ← 最優先

**サービスタグは7桁の英数字**で、「Service Tag」または「ST」の文字とバーコードが併記されている。本体のシールを探す。

**起動できたなら、コマンドでも取れる:**
```
sudo cat /sys/class/dmi/id/product_serial
```

**保証が残っているなら、開けるより先に Dell に連絡する方が得。** オンサイト保証なら技術者が来る。自分で開けて状況が変わると対応が面倒になることがある。

### B. ケースを開けて4箇所を挿し直す

**間欠的に落ちる原因として最も多く、最も安い。** 工具も部品も要らない。

| 挿し直す場所 | なぜ |
|---|---|
| **GPUの補助電源ケーブル**（グラボに挿さる太い線） | 半挿しだと「落ちる＋映らない」を両方説明できる |
| **GPU本体**（一度抜いて挿し直す） | 接点の酸化・微妙な浮き |
| **メモリ**（全部抜いて挿し直す） | 同上 |
| **24ピン／CPU 8ピン電源** | 電源系の接触不良 |

### C. ホコリを飛ばす

**数週間、毎日数時間の 4096env 学習を回していた。** ファンとヒートシンクにホコリが詰まっていれば、熱保護で落ちる。

### D. モニターのポートとケーブルを変える

**まだ試していない。** グラボの別の穴（HDMI ↔ DisplayPort）に挿し替えるだけ。**特定の出力端子だけが死ぬ故障は普通にある。**

## 8. ★ 左サイドパネルの外し方（Dell 公式手順・ネジ1本）

**先に電源ケーブルをコンセントから抜き、電源ボタンを15秒長押しする。**

1. **本体を背面から見て左側**（正面から見て右側）が開く面
2. **背面の端に、手で回せるつまみネジが1本**ある。これを緩める。**ネジは外れず本体に付いたまま**（脱落防止式）。**工具不要**
3. ネジの近くに**パネルを外すためのラッチ（レバー）**がある。**手前に引く**
4. パネルが浮くので、**そのまま持ち上げて外す**

出典: [Removing the left-side cover — Alienware Aurora R16 Owner's Manual (Dell)](https://www.dell.com/support/manuals/en-us/alienware-aurora-r16-desktop/alienware-aurora-r16-owners-manual/removing-the-left-side-cover?guid=guid-2aba09f1-07ae-4ce4-aa2b-6c47dc9d571e&lang=en-us)

**開けたら写真を1枚撮る。** そこから SSD の位置・GPU の補助電源・水冷ポンプを確認する。

## 9. Step 3 — コード別の対処（コードが出た場合）

### コード 2,3 / 2,4 / 2,5 / 4,1（メモリ系）
メモリを全部抜いて1枚だけ挿して起動 → 1枚ずつ、スロットを変えながら試す。**挿し直すだけで直ることが多い。**

### コード 3,2（ビデオカード）
**GPU の補助電源の挿し直し → GPU の挿し直し → §9-D。** 数週間の連続高負荷を経ているので劣化は十分ありうる。

### コード 3,5 / 4,2（電源系）
CPU 補助電源（8ピン／4+4ピン）と 24ピン ATX の挿し直し。**電源ユニットの劣化を疑う。**
**Aurora R16 は電源ユニットが独自形状の場合がある。交換は Dell 純正品か、対応を確認してから。**

### D. GPU を抜いて電源だけ見る（★単一変数のテスト）

**KF CPU なので画面は出ないが、「電源が落ちるかどうか」だけは見られる。**

| 結果 | 意味 |
|---|---|
| **GPU 無しなら落ちない（十数分以上）** | **GPU が電源断の原因。** GPU 故障で確定に近い |
| GPU 無しでも落ちる | GPU は無関係。電源ユニット／CPU／基板／熱を疑う |

**★ただし持続時間がばらつくので、1回の結果で判断しない。** 同じ条件（休止時間を揃える）で複数回測る。

### コード 2,1（CPU）/ 2,2 / 2,6（基板）
ユーザー側でできることは少ない。CPU 補助電源の確認と CMOS クリアまで。

### コード 3,1（CMOS 電池）
ボタン電池（CR2032）を交換。安価で、BIOS 設定が初期化される。

## 11. 分解するときの安全ルール

- **必ず電源ケーブルをコンセントから抜く。** スイッチを切るだけでは不十分
- **電源ボタンを15秒長押しして放電**してから内部に触る
- **金属部分（ケースのフレーム）に触れて静電気を逃がしてから**部品に触る
- **熱くなっている可能性がある。** 電源を切った直後は触らない。30分待つ
- **コネクタは真っ直ぐ抜き差しする。** こじると基板を傷める
- **写真を撮ってから外す**

## 12. やってはいけないこと

- **保証が残っているのに、確認せず分解する。** 先に §7-A
- **電源ユニットを開ける。** 内部に高電圧のコンデンサがあり、抜いた後も危険
- **原因不明のまま何度も電源を入れ直す。** 熱が原因なら悪化させる
- **SSD を初期化する**
- **修理に出す前に SSD を抜き忘れる**（§5）
- **`unattended-upgr` を kill する。** dpkg のデータベースが壊れる。**数分待つ**

## 15. この作業で守る原則（手順書 A1 より）

- **推測で進めない。** 症状だけで原因を断定せず、**事実（LEDコード・サービスタグ・ポンプの動作）**を先に取る
- **★自分のモデルが観測と合わなくなったら、モデルを捨てる。** 2026-09-14 に「熱依存」モデルが持続時間の逆転で棄却された
- **破壊的操作の前にバックアップ。** ここでは「修理に出す前に SSD を抜く」
- **一度に1つだけ変える。** メモリを1枚ずつ、GPU を抜く・戻す。**同時に複数変えると切り分けにならない**
- **★持続時間がばらつくので、1回の結果で判断しない。** 休止時間を揃えて複数回測る
