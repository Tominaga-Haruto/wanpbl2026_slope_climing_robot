# D9（仮）: 吊り支持での両CAN受信確認

> この文書は、D9を安全に着手できるか確かめるための**送信なし**の手順である。方策、T265、コントローラー、MIT位置指令、トルク指令は使わない。これだけではD9完了ではない。

## 現在の境界

- D8はPC乾式で、42要素観測→ONNX→H順10目標角→D4/D7のCAN順計画まで確認済み。
- `ver9_integration.py` はCANを開かず、送信不能である。
- 現在の `cubemars.py` のMITフレーム実装はD9の送信器に使わない。既存文書でペイロード順・レンジが不正確と明記されている。
- T265の実機 `R_OFFSET=[x,y,z] m` は文書中に3軸数値として残っていない。今回はT265を起動しない。

したがって今回の到達点は、**吊り支持中に両CANチャネルから全10軸の新鮮なフィードバックを受け、何も送信せずに終了すること**だけである。

## 開始条件

全項目が満たせない場合は、通電しない。

- [ ] ロボットは床から完全に離れ、棒または治具で自立支持されている。手で支えるだけは不可。
- [ ] 支持具、ケーブル、T265、脚が互いに接触・引っ掛かり・荷重を受けない。
- [ ] 主電源を一動作で切れる位置に置いた。操作担当と電源遮断担当を分けられるなら分けた。
- [ ] D7後に部品脱着、配線変更、基準姿勢からの軸回転をしていない。該当するならD7を先に再実施する。
- [ ] USB2CANのch=0は左脚5軸、ch=1は右脚5軸につながっている。
- [ ] ノートPCの `C:\Users\harut\Connect2USB2CAN` に `d7_origin_console.py` がある。

想定外の動き、異音、支持ずれ、ケーブルの張り、警告表示のいずれかが出たら、操作を続けず主電源をOFFにする。ソフトウェア操作は非常停止の代わりにならない。

## 実行手順

### 1. 通電前

1. 主電源がOFFであることを確認する。
2. 棒・治具・吊り点・ケーブルを写真に残す。少なくとも正面と左右側面を撮る。
3. 機体を手放しても、落下・回転・ずれがないことを確認する。
4. USB2CANをノートPCへ接続する。

### 2. 受信だけを開始する

1. 主電源をONにする。
2. 何も送らず3秒待つ。
3. ノートPCのPowerShellで、次を1行ずつ実行する。

```powershell
cd C:\Users\harut\Connect2USB2CAN
py -3.13 d7_origin_console.py
```

4. コンソールで次だけを入力する。

```text
scan 3
```

`scan` は両チャネルを受信するだけで、原点設定・MIT・トルク・位置指令を送らない。

### 3. 判定

以下の10台すべてが表示され、`err=0`、`age <= 0.3 s`であることを確認する。

| ch | H関節 | ID | 機種 |
|---:|---|---:|---|
| 0 | LL_HR | `0x13` | AK10-9 |
| 0 | LL_HAA | `0x1B` | AK10-9 |
| 0 | LL_HFE | `0x2A` | AK80-9 |
| 0 | LL_KFE | `0x12` | AK10-9 |
| 0 | LL_FFE | `0x22` | AK80-9 |
| 1 | LR_HR | `0x1C` | AK10-9 |
| 1 | LR_HAA | `0x11` | AK10-9 |
| 1 | LR_HFE | `0x21` | AK80-9 |
| 1 | LR_KFE | `0x1A` | AK10-9 |
| 1 | LR_FFE | `0x2B` | AK80-9 |

一台でも欠ける、`err!=0`、`age > 0.3 s`、異音、支持ずれがあれば、コンソールで追加操作をせず主電源をOFFにする。この時点で今回を終了する。

### 4. 正常時の終了

1. `q` を入力してコンソールを終了する。D7コンソールの `q` はCANへ送信しない。
2. 主電源をOFFにする。
3. `C:\Users\harut\Connect2USB2CAN\logs\d7_origin\session_日付_時刻.txt` を保存する。
4. 次の表を埋める。

| 項目 | 結果 |
|---|---|
| 支持が手放しで安定した | はい / いいえ |
| ch=0の5軸 | 全数 / 欠けあり |
| ch=1の5軸 | 全数 / 欠けあり |
| `err=0` | 全数 / 異常あり |
| 新鮮なフィードバック | 全数 / 異常あり |
| 送信数 | 0 |
| 異音・支持ずれ・ケーブル干渉 | なし / あり |
| セッションログの絶対パス | |

## 次の停止点

この受信確認に合格しても、MIT送信や方策実行へ進まない。次に必要なのは、次の4点を別途そろえたD9送信器の実装・乾式テストである。

1. 実測済みのmode 8ペイロード・機種別速度レンジを使う、両CANチャネル用のMITフレーム生成器。
2. Hの関節別stiffness/dampingを、AK10-9 / AK80-9の実測係数へ換算した10軸Kp/Kd表。
3. 1軸だけで、ゼロ速度・ゼロトルク・既定姿勢目標を50 Hz送信し、意図した角度へ動くことの確認。
4. T265を使う方策段階より前に、CADの実測 `R_OFFSET=[x,y,z] m` を確定値として入力すること。

上記が実装・レビューされ、ユーザーがあらためて実機MIT送信を明示したときだけ、1モーター → 片脚 → 全身（吊り）の順に進む。
