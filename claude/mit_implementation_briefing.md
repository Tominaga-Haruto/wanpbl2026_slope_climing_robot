## 2. いま詰まっているところ — MIT の位置原点

**MIT の位置原点はサーボの原点と別物。** その差がまるごと偏差になる。

| やったこと | 結果 |
|---|---|
| サーボ角をそのまま MIT の目標位置に（Kp=2） | **16.5 A** |
| 同じ条件で 90度ステップ（Kp=5） | **39.7 A**（Bus Current Limit 35A 超） |
| ゴミ原点のまま `hold 1 0 2`（**Kd=0**） | **277 deg/s の暴走**（減衰が無く発振） |

### `morg` の原理

Kp を小さく固定して目標位置 X を5点振り、電流を直線で当てて**ゼロ交差を外挿**する。

```
I = (Kp_eff / Kt) × ((X − θ_servo) − offset)
```

**ゼロ交差は傾きに依存しない**ので、**Kt も Kp のスケールも未知のまま offset が求まる。**
サンプルごとに θ_servo を読んで差を取るので、軸が多少動いても効かない。
2回目以降は前回の推定値を中心に振る＝外挿でなく内挿になり精度が上がる。

### ver6 に入れた安全弁

- **当てはまりが悪ければ原点を採用しない。** R² < 0.70 または傾き < 0.02 A/rad なら位置指令はロックのまま。
  **ゴミ原点で `hold` を許したのが 277 deg/s の直接原因**なので、ここが一番効く。
- **Kp>0 で Kd=0 を禁止。**
- 毎回「実際に送られる Kp/Kd」を表示（量子化の可視化）。
- `log on` でセッション記録をファイルに残す。

**★ 修正後の `morg` はまだ実行していない。次のセッションの最初の一手。**

## 3. Kp / Kd / トルク上限の初期値

| 項目 | シム側 | 実機で入れる値 | 根拠 |
|---|---|---|---|
| damping → Kd | 1.5 | **指令 3.1** | 実効Kd = 指令×0.48（実測） |
| stiffness → Kp | 15 | **不明。まず 2〜5 から** | **Kp のスケールは未測定（E5b）** |
| effort_limit（AK80-9） | 9 N·m（定格） | まず 4〜5 N·m に絞る | 初回はトルクを絞る |
| effort_limit（AK10-9） | 18 N·m（定格） | 同上、半分から | 同上 |

**Kp に係数が無いとは限らない。** Kd に 0.48 があった以上、素通しと決めつけない。
事故ログからの概算は 0.43 倍だが、ゴミ原点を偏差と仮定した値なので当てにならない。

## 5. 安全チェックリスト（毎回）

- [ ] モーターは脚に接続されていない、または脚が固定/吊られている
- [ ] `model` の表示が実機の機種と一致している（トルクレンジ 3.0 倍差）
- [ ] Kp が 0.06 以上（未満だと量子化で 0 になる）

- [ ] `x`（または電源off）がいつでもすぐ使える状態
- [ ] 異音・`err` 非ゼロ・温度急上昇・意図しない動作が出たら即電源off
- [ ] **バスが落ちたら: 電源OFF → USB2CAN 抜き差し → 10秒 → 電源ON。** 再起動だけでは戻らない

## 7. ユーザーについて（対話の注意・手順書A1と同じ）

- **ターミナルの長文は読まない。** エラーは要点を訳し、次に打つコマンドを1〜2個に絞る。
- **山括弧プレースホルダは絶対に使わない。** 実名を埋めた完成形のコマンドを出す。
- **長いコマンドは改行なしの1行版で、実行ディレクトリを明示する。**
- **数字で語ると納得される。**
- **前に進めたがる。** 冗長な確認や既出事実の繰り返しを嫌う。
- **実機は物理的に動く。** 指令コードを実行する前は必ず「そのコマンドで何が起きるか」を先に説明する。
