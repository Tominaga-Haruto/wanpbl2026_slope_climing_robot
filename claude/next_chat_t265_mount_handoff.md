# T265取付け・観測の引継ぎ（D3 / M6）

## ゴールと範囲

T265をロボットへ剛固定し、base座標の観測をver9へ安全に渡せる状態にする。

**この作業ではモーターを通電・CAN送信・方策送信しない。** `t265_check.py` はT265の読取りとCSV記録だけを行う。

## 先に読むもの

1. `deployment_03_t265_mount_instruction.md`
2. `realsense_t265.md`
3. `robot_model_conventions.md` §1
4. この文書

作業前にリポジトリで `git status --short` を確認し、既存の未整理変更を触らない。

## すでに確定していること（やり直さない）

- T265はノートPCで200 Hz取得済み。Pythonは `C:\Users\harut\Connect2USB2CAN\.venv310`（Python 3.10、pyrealsense2 2.53.1.4623）。2.54以降へ更新しない。
- base座標は `+X 前, +Y 左, +Z 上`。レンズ前向き・水平なら `R_CB` は既存値を使う。
- 前向き・水平での静止・前進・左移動・前下げ・反時計回りの符号は、`C:\Users\harut\Connect2USB2CAN\t265\logs\t265_20260917_213011.csv` ほかで確認済み。
- T265のtracking centerは左右イメージャの中点。CADの開口左端から45.000 mm、waist右端から左へ234.000 mm、waist下辺から上へ67.750 mm（開口上下中央）である。

## 今回必ず行うこと

### 1. 剛固定と写真

1. T265をwaist前面の長方形開口へ、**レンズ前向き・水平**で固定する。開口が向く方向をロボットの正面とする。
2. 手で軽く揺らして、位置・向きが変わらないことを確認する。ケーブルに引かれて姿勢が変わる固定は不可。
3. 正面、側面、固定具・USBケーブル取り回しが分かる写真を残す。

### 2. `R_OFFSET` を確定する

`R_OFFSET` はbase原点から**tracking center**までのベクトル `[m]` であり、筐体角やレンズ片側ではない。

1. CADで、waist外形の「右端」「下辺」とbase原点の関係を確認する。base原点に対するwaist右端・下辺の3軸位置を測るか、base原点からtracking centerを直接測る。
2. 固定後の前後（奥行き）位置も測る。tracking centerはT265背面から5.95 mmであり、前面開口に対する奥行きを推測しない。
3. 以下をmmとmの両方で記録する。符号は必ずbase座標に従う。

   ```text
   R_OFFSET = [x, y, z] m  # base原点 → tracking center
   CAD/実測の基準面:
   奥行きの測定基準:
   測定者・日付:
   ```

4. 3軸のいずれかが不明なら `t265_check.py` の `R_OFFSET` は0のままにし、推測値を書き込まない。

### 3. 取付け状態でのT265試験

次を実行する。CAN・モーターには接続しない。

```powershell
cd C:\Users\harut\Connect2USB2CAN
.venv310\Scripts\python t265\t265_check.py --raw
```

1. 60秒以上静止してCSVを残す。200 Hz前後、confidenceが2以上を保つこと、途絶表示が無いことを確認する。
2. 機体を安全に保持したまま、T265取付け部・USBケーブルに軽い振動を加える。固定の緩み、confidence低下、途絶をCSVと写真に残す。
3. 吊り下ろし試験を行える安全な支持がある場合だけ、モーター無通電で短時間実施し、同じCSVを残す。支持方法、時間、confidenceの最小値、途絶の有無を書く。
4. confidenceが1以下、または途絶が出た場合は、固定・USB・視界を点検してそこで停止する。停止処理を未実装の方策へ接続しない。

### 4. 既存5動作CSVを再取得する条件

取付け後もレンズ前向き・水平が保てているなら、既存CSVを再利用してよい。以下のいずれかなら今回再取得する。

- 上下・左右・前後の向きが既存確認時と異なる。
- 固定後にカメラが回った／傾いた。
- 試験中の符号表示に疑義がある。

再取得時の期待値は、静止で `g_b.z ≈ -1`、前進で `v_b.x > 0`、左移動で `v_b.y > 0`、前下げで `g_b.x > 0`、上から反時計回りで `w_b.z > 0`。一つでも逆なら符号をその場で変更せず、写真・CSV・実際の取付け向きを記録して停止する。

## 今回の完了条件

- T265が剛固定され、写真がある。
- `R_OFFSET` の3軸値と測定基準が記録されている。
- 取付け状態の静止CSVと、可能なら振動／吊り下ろしCSVがある。
- 取付け向きが既存と同じか、異なる場合は新しい5動作CSVで `R_CB` を確認済み。

## この後に残る実装作業（今回の物理取付け後）

1. `t265_check.py` の `R_OFFSET` を、確定値だけで更新する。
2. ver9ではT265を別プロセスにし、最新観測と時刻を共有する。
3. T265途絶またはconfidence低下で、受け手側が停止へ遷移するよう実装・乾式試験する。学習側の安全境界は「直前値保持を最大0.2秒、その後停止」である。
4. CAN、コントローラー、ONNXを含めた50 Hz統合試験は、D2・D4・M5と停止処理の完了後にのみ進む。

## 引継ぎ時に必ず残すもの

- 取付け写真、CSVの絶対パス、`R_OFFSET`、`R_CB`、固定方法。
- confidenceの最小値、途絶の有無、異常時に止めた地点。
- 変更したファイルのdiffと、`git status --short`。
