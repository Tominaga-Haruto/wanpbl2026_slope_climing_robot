### 1-3. ゲイン換算（09-17、脚を外して実測。指令トルク単位）

| | ID34 AK80-9（右足首） | ID18 AK10-9（右膝） |
|---|---|---|
| c_p（実効Kp/指令Kp） | **0.523**（Kp 1/2/5 で 0.521〜0.529） | **1.258**（1.229〜1.262） |
| c_d（実効Kd/指令Kd） | **0.523** | **1.216** |
| c_p / c_d | 1.00 | 1.03 |
| 指令 Kp（シム stiffness 15 の例） | stiffness ÷ 0.523 = 28.7 | stiffness ÷ 1.258 = 11.9 |
| 指令 Kd（シム damping 1.5 の例） | damping ÷ 0.523 = 2.87 | damping ÷ 1.216 = 1.23 |
| \\|電流\\|/トルク指令 | 1.79 A/(N·m) | 0.77 A/(N·m) |
| \\|電流\\|/(指令Kp·rad) | 0.94 | 0.97 |
| 摩擦/c_d（回転テスト） | 0.30 | 0.36 |
| 原点 offset（`mit_calib.json`） | −0.0017 rad | −0.0053 rad |

- **Kd の分離は決着（M2 済み）。** 各機種で c_p ≈ c_d なので、Kp・Kd を機種ごとの係数で割ればシムの stiffness:damping 比は保たれ、実効 damping ×1.0。「damping ×2 が不合格帯」の心配は、換산을 機種別にすれば消える。
- 09-16 の ID34 脚付き c_p 0.538 と 09-17 脚なし 0.523 は 3% 差。
- **新しい論点（Kt が後回しにできなくなった）:** 「指令Kp×角度差 → 電流」は機種によらずほぼ同じ（0.94 / 0.97）で、機種で違うのはトルク指令の目盛り（2.3 倍）。つまり **「指令トルク単位 = 物理 N·m」かは機種ごとに違いうる。** シムは stiffness ×0.7 が不合格帯なので、物理 N·m で合っているかは Kt（F5b）で確かめる必要がある。
- ver8 の Kp 上한은 20 → AK80-9 のシム stiffness に届かない可능性。**WRS 側 H_eff13p5 のアクチュエータ설정（그룹ごとの stiffness / damping / effort）をもらって관절ごとの指令 Kp・Kd 表を작성し、ver9 の上한을 결정한다.**

| | **`vscale`** | **静止テスト（c_d×r_v）＋回転テスト（Kd 1/2/3 で +300° 回って戻る ×3 → r_v と c_d を分離）。脚を外す・本体固定・手を離す。** 結果は `mit_calib.json` の `vscale` |
| | `wdog` | 0.15 N·m を 1 秒送って送信だけ止め、3 秒電流を見る（指令途絶の確認） |
| | `lat` | 指令 → 電流変化の受信までの遅れ（20 回） |
| 原点 | **`morg`** / `morg fine` | MIT の原点を \\|電流\\| の V 字の底で実測（数 deg 動く）。`fine` は寄せを省略 |
| | **`overify`** | 原点の左右 ±0.15 rad で \\|電流\\| が揃うか → 「原点は合っています（残差 2 deg 以内）」で `原点OK` |
| | `o 0` | 今の位置を 0 と定義（モード5）。**軸は動かない**。サーボ角と MIT 位置の両方が 0 に。打ったら原点は未検証に戻る |
| | `ocheck` / `ofit` / `oclear` | `o 0` で MIT 原点も動くか／複数の morg から当てはめ／原点をメモリから消す |
| 位置系（原点OK が要る） | `hold 2 1 3` | Kp 2・Kd 1 で今の位置を 3 秒保持（**Kp>0 なら Kd≥0.3**） |
| | **`kpscale`** | Kp 1/2/5 で「Kp×角度差」と「トルク指令」の電流を比べて c_p。ほぼ動かない。結果は `mit_calib.json` の `kpscale` |
| | `ramp 1 3` | Kd 1 で Kp を 2→5→10→15 と上げ各 3 秒保持（リミットサイクル確認） |
| | `step 5 15 1 2` | 5° のステップを Kp 15・Kd 1 で 2 秒 |
| 止める | `x` | 零指令 3 回（ソフト停止） |
| | `q` | 零指令を送って切断・終了 |

**起動直後に「状態なし」**: モーター電源を入れた直後は数秒フィードバックが来ない。待って `s`、続くなら `q` → 起動し直す。**「スクリプトの再起動」と「モーター電源の入れ直し」は別物（入れ直すと角度が変わりうる）。**
