## 旋回を入れるとき（2026-09-23 の整理）

指令契約は元から `(vx, vy, wz)`。1つの方策で歩行も旋回もするなら、モード切替ボタンは不要で、右スティック左右を `wz` に割り当てて符号を乾式で確かめるだけでよい。旋回を学習していない方策（H）を載せる間は `wz=0` に固定するフラグで足りる。歩行用と旋回用の2方策をボタンで切り替える形は、ONNX 2つ・切替時のゼロ指令・切替中の転倒対策が要るので避ける。
