# D7: 棒支持での全10関節原点設定

**今回の目的:** 棒にまたがらせて機械的に固定した現在の基準姿勢を、全10モーターの MIT 座標の `0 rad` として登録する。D8 が使う「H関節角 ↔ MIT角」の原点変換表を残す。

**今回しないこと:** 軸を動かす指令、`morg`、`overify`、`jog`、`hold`、`step`、トルク指令、方策送信。使うコンソール操作は `s`（状態表示）と `o 0`（現在角をゼロとして登録）だけ。`o 0` は軸を動かさない。

**非常停止:** 想定外があればコンソール操作を続けず、手元の**主電源をOFF**にする。`x` は非常停止の代わりにしない。

---

## 0. 開始判定（ここで止まってよい）

次の全てが「はい」のときだけ、手順1へ進む。

- [ ] 以後の部品脱着、配線変更、T265取付け変更は予定していない（D6完了）。
- [ ] 機体は棒・治具で自立しており、手で支え続けなくても落下・回転・ずれが起きない。
- [ ] 棒はケーブル、関節、T265、胴体を押したり引っ張ったりしていない。
- [ ] 主電源スイッチをすぐ切れる位置に置いた。
- [ ] 現在の姿勢を次回も再現できるよう、棒の位置・接触点・寸法を記録できる。

一つでも「いいえ」なら、今回は `o 0` を送らない。固定または構成を整えてから最初から実施する。

## 1. 通電前に基準姿勢を記録する

1. **主電源がOFF**であることを確認する。
2. 棒にまたがる支持を確認する。棒がずれないこと、機体を手放しても姿勢が変わらないことを確認する。
3. 基準姿勢を目視する。両脚はほぼ真下、爪先はbaseの `+X`（前）、足裏はほぼ水平、左右HAAと股ひねりは0付近にする。
4. 次の写真を撮る。写真には棒と支持点も入れる。
   - [ ] 正面
   - [ ] 左側
   - [ ] 右側
   - [ ] 上面または棒との接触が分かる角度
5. 次をメモする。
   - 棒の高さ・直径・機体のどこに接触しているか
   - 棒から左右の股関節中心、足先までの寸法または再現用の目印
   - ケーブルの取り回し

**停止:** 写真と寸法だけで同じ姿勢へ戻せないなら、原点化しない。

## 2. 全10台のフィードバックを確認する

1. USB2CANをノートPCへ接続する。
2. 主電源をONにする。
3. 軸には何も指令せず、数秒待つ。
4. ノートPCの PowerShell で、次を**1行ずつ**実行する。

```powershell
cd C:\Users\harut\Connect2USB2CAN
py -3.13 motor_console_ver8.py
```

5. コンソールで、次を**1行ずつ**入力する。

```text
log on
sniff 3
scan 3
```

6. `scan 3` の結果で、10台すべてが見え、全行 `err=0` であることを確認する。

**停止:** 10台そろわない、`err!=0`、フィードバック欠落、異音、支持ずれ、ケーブルの引っ張りが一つでもあれば、主電源をOFFにして終了する。

## 3. 原点を設定する

下表の順で、各ブロックを**1行ずつ**入力する。`s` の表示が新鮮で `err=0` であることを確認してから `o 0` を入力する。最後の `s` で角度が0付近かつ `err=0` を確認し、表へ記録してから次の軸へ進む。

| 順 | H関節 | `id` | `model` | 入力する5行 |
|---:|---|---:|---|---|
| 1 | LL_HR | 19 | AK10-9 | `id 19` → `model AK10-9` → `s` → `o 0` → `s` |
| 2 | LR_HR | 28 | AK10-9 | `id 28` → `model AK10-9` → `s` → `o 0` → `s` |
| 3 | LL_HAA | 27 | AK10-9 | `id 27` → `model AK10-9` → `s` → `o 0` → `s` |
| 4 | LR_HAA | 17 | AK10-9 | `id 17` → `model AK10-9` → `s` → `o 0` → `s` |
| 5 | LL_HFE | 42 | AK80-9 | `id 42` → `model AK80-9` → `s` → `o 0` → `s` |
| 6 | LR_HFE | 33 | AK80-9 | `id 33` → `model AK80-9` → `s` → `o 0` → `s` |
| 7 | LL_KFE | 18 | AK10-9 | `id 18` → `model AK10-9` → `s` → `o 0` → `s` |
| 8 | LR_KFE | 26 | AK10-9 | `id 26` → `model AK10-9` → `s` → `o 0` → `s` |
| 9 | LL_FFE | 34 | AK80-9 | `id 34` → `model AK80-9` → `s` → `o 0` → `s` |
| 10 | LR_FFE | 43 | AK80-9 | `id 43` → `model AK80-9` → `s` → `o 0` → `s` |

実機→Hの符号は全軸 `+1`。この表の `id` は10進数である。

**停止:** いずれかの `s` が状態なし・古い時刻・`err!=0`・不自然な角度変化を示したら、主電源をOFFにする。残りの軸は実施しない。

## 5. 終了と完了判定

1. 全行が記録できたら、コンソールに `q` を入力する。
2. 主電源をOFFにする。
3. `log on` のログを保管する。通常は `C:\Users\harut\Connect2USB2CAN\logs\v7_日付\session_時刻.txt` にある。
4. 次の全てを満たせばD7完了。

- [ ] 10軸すべてで、設定前後の `s` を記録した。
- [ ] 10軸すべてで設定後角度が0付近、`err=0` だった。
- [ ] 基準姿勢の写真、棒の支持点、再現用の寸法を残した。
- [ ] D4の原点欄へ、この記録を転記できる状態にした。

## 6. D7完了後の扱い

この作業で確認できるのは、**この基準姿勢における**MIT座標とH関節角の対応だけ。電源断、軸の回転、部品脱着、配線変更、支持姿勢の変更の後は、原点が残ると仮定せず、この手順を最初からやり直す。

次の段階はD8のPC上統合であり、方策送信や全身動作ではない。実機へ位置指令を出す段階では、1モーター → 片脚 → 全身の順を守る。
