# D7: 棒支持での全10関節原点設定

**今回の目的:** 棒にまたがらせて機械的に固定した現在の基準姿勢を、全10モーターの MIT 座標の `0 rad` として登録する。D8 が使う「H関節角 ↔ MIT角」の原点変換表を残す。実機はCANを2系統に分けているため、D7専用の両チャネルコンソールを使う。

**今回しないこと:** 軸を動かす指令、`morg`、`overify`、`jog`、`hold`、`step`、トルク指令、方策送信。使うコンソール操作は `s`（状態表示）と `o 0`（現在角をゼロとして登録）だけ。`o 0` は軸を動かさない。

**非常停止:** 想定外があればコンソール操作を続けず、手元の**主電源をOFF**にする。`x` は非常停止の代わりにしない。

---

## 0. 開始判定（ここで止まってよい）

次の全てが「はい」のときだけ、手順1へ進む。

- [ ] 以後の部品脱着、配線変更、T265取付け変更は予定していない（D6完了）。
- [ ] 機体は棒・治具で自立しており、手で支え続けなくても落下・回転・ずれが起きない。
- [ ] 棒はケーブル、関節、T265、胴体を押したり引っ張ったりしていない。
- [ ] 主電源スイッチをすぐ切れる位置に置いた。
- [ ] 現在の姿勢を次回も再現できるよう、棒の位置・接触点・寸法を記録できる。

一つでも「いいえ」なら、今回は `o 0` を送らない。固定または構成を整えてから最初から実施する。

## 1. 通電前に基準姿勢を記録する

1. **主電源がOFF**であることを確認する。
2. 棒にまたがる支持を確認する。棒がずれないこと、機体を手放しても姿勢が変わらないことを確認する。
3. 基準姿勢を目視する。両脚はほぼ真下、爪先はbaseの `+X`（前）、足裏はほぼ水平、左右HAAと股ひねりは0付近にする。
4. 次の写真を撮る。写真には棒と支持点も入れる。
   - [ ] 正面
   - [ ] 左側
   - [ ] 右側
   - [ ] 上面または棒との接触が分かる角度
5. 次をメモする。
   - 棒の高さ・直径・機体のどこに接触しているか
   - 棒から左右の股関節中心、足先までの寸法または再現用の目印
   - ケーブルの取り回し

**停止:** 写真と寸法だけで同じ姿勢へ戻せないなら、原点化しない。

4. ノートPCの PowerShell で、次を**1行ずつ**実行する。

5. コンソールで、次を入力する。`scan` はch=0/ch=1を同時に聞くだけで、CANへ送信しない。

## 3. 原点を設定する

下表の順で、各ブロックを**1行ずつ**入力する。IDは必ず16進数で入力する。`s` の表示が新鮮で `err=0` であることを確認してから `o` を入力する。`o` の後、表示された対象IDと同じ `YES 0x..` を入力したときだけ原点設定が送られる。最後の `s` で角度が0付近かつ `err=0` を確認し、表へ記録してから次の軸へ進む。

| 順 | H関節 | ch | モーターID | 入力する操作 |
|---:|---|---:|---|---|
| 1 | LL_HR | 0 | `0x13` | `s 0x13` → `o 0x13` → `YES 0x13` → `s 0x13` |
| 2 | LR_HR | 1 | `0x1C` | `s 0x1C` → `o 0x1C` → `YES 0x1C` → `s 0x1C` |
| 3 | LL_HAA | 0 | `0x1B` | `s 0x1B` → `o 0x1B` → `YES 0x1B` → `s 0x1B` |
| 4 | LR_HAA | 1 | `0x11` | `s 0x11` → `o 0x11` → `YES 0x11` → `s 0x11` |
| 5 | LL_HFE | 0 | `0x2A` | `s 0x2A` → `o 0x2A` → `YES 0x2A` → `s 0x2A` |
| 6 | LR_HFE | 1 | `0x21` | `s 0x21` → `o 0x21` → `YES 0x21` → `s 0x21` |
| 7 | LL_KFE | 0 | `0x12` | `s 0x12` → `o 0x12` → `YES 0x12` → `s 0x12` |
| 8 | LR_KFE | 1 | `0x1A` | `s 0x1A` → `o 0x1A` → `YES 0x1A` → `s 0x1A` |
| 9 | LL_FFE | 0 | `0x22` | `s 0x22` → `o 0x22` → `YES 0x22` → `s 0x22` |
| 10 | LR_FFE | 1 | `0x2B` | `s 0x2B` → `o 0x2B` → `YES 0x2B` → `s 0x2B` |

実機→Hの符号は全軸 `+1`。D7ではモーターIDを16進数で統一する。

**停止:** いずれかの `s` が状態なし・古い時刻・`err!=0`・不自然な角度変化を示したら、主電源をOFFにする。残りの軸は実施しない。

1. 全行が記録できたら、コンソールに `q` を入力する。D7コンソールの `q` はCANへ何も送らない。
2. 主電源をOFFにする。
3. `C:\Users\harut\Connect2USB2CAN\logs\d7_origin\session_日付_時刻.txt` を保管する。
4. 次の全てを満たせばD7完了。

- [ ] 10軸すべてで、設定前後の `s` を記録した。
- [ ] 10軸すべてで設定後角度が0付近、`err=0` だった。
- [ ] 基準姿勢の写真、棒の支持点、再現用の寸法を残した。

## 6. D7完了後の扱い

この作業で確認できるのは、**この基準姿勢における**MIT座標とH関節角の対応だけ。電源断、軸の回転、部品脱着、配線変更、支持姿勢の変更の後は、原点が残ると仮定せず、この手順を最初からやり直す。

次の段階はD8のPC上統合であり、方策送信や全身動作ではない。実機へ位置指令を出す段階では、1モーター → 片脚 → 全身の順を守る。
