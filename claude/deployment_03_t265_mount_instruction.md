# D3: Hが必要とするbase速度観測を実機で作る

## 対応するロードマップ

- §3-2 前半（取付け向き・位置、R_CBとR_OFFSETの確定）
- §4 本文のT265観測入力

## 目的

Hはbase linear velocityを観測に使うため、T265をロボット座標のbase姿勢・速度へ変換してver9へ渡せるようにする。

## 待つもの

待たない。既存の `realsense_t265.md` にWindows側の200 Hz取得と座標変換の確定事項がある。最終の42次元に入れる位置だけが `obs_contract.md` 待ちである。

## 実施内容

1. T265の物理取付け方向とbaseからの位置を記録する。
2. `realsense_t265.md` の既定変換を用い、カメラ出力からbase座標の姿勢・角速度・線速度を出す小部品を作る。
3. 静止・既知の手動移動で、baseの前後・左右・上下と出力軸の対応を記録する。
4. ver9のスナップショット形式へT265データと取得時刻を入れる。

## 完了条件

base座標の `lin_vel_x, lin_vel_y, ang_vel_z` を、時刻つきでver9へ供給できること。振動・confidence・途絶の試験は、機能だけを最短で通す今回の範囲外とする。
