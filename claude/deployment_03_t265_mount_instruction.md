# D3: Hが必要とするbase速度観測を実機で作る

## 対応するロードマップ

- §3-2 前半（取付け向き・位置、R_CBとR_OFFSETの確定）
- §4 本文のT265観測入力

## 目的

Hはbase linear velocityを観測に使うため、T265をロボット座標のbase姿勢・速度へ変換してver9へ渡せるようにする。

## 待つもの

待たない。既存の `realsense_t265.md` にWindows側の200 Hz取得と座標変換の確定事項がある。最終の42次元に入れる位置だけが `obs_contract.md` 待ちである。

## 実施内容

### 今日の実機手順（モーター通電なし）

1. T265を、レンズが機体の前方を向き、水平になる向きで胴体へ固定する。仮固定でも、手で揺らして位置・向きが変わる固定は使わない。
2. base原点からT265本体の基準点までを、base座標の `(+X 前, +Y 左, +Z 上)` で測って記録する。値は `R_OFFSET` として使うため、目測で埋めない。CAD値が得られるならCADを正とする。
3. ノートPCの `C:\Users\harut\Connect2USB2CAN` で `.venv310\Scripts\python t265\t265_check.py --raw` を起動する。これはT265の読取とCSV記録だけで、CAN・モーター制御は行わない。
4. 静止、前へ手動移動、左へ手動移動、前を下げる、上から見て反時計回り、の順で小さく動かし、CSVを残す。レンズ前向き・水平なら、静止時 `g_b.z` は約-1、前進は `v_b.x` 正、左移動は `v_b.y` 正、反時計回りは `w_b.z` 正である。
5. 一つでも軸が逆なら、その場で座標の符号を推測で直さない。T265の実際の取付け方向とログを記録して停止し、`R_CB`を再計算する。

### 実装へ渡す値

1. 確定した取付け向きから `R_CB` を決める。レンズ前向き・水平の既定値は `realsense_t265.md` §4 にある。
2. 測定したbase原点→T265位置を `R_OFFSET` に入れる。
3. T265データと取得時刻をver9のスナップショット形式へ渡す。T265はver9で別プロセスとし、途絶時は停止へ遷移させる。

## 完了条件

base座標の `lin_vel_x, lin_vel_y, ang_vel_z` を、時刻つきでver9へ供給できること。今日の完了物は、取付け写真、`R_CB`、`R_OFFSET`、5動作のCSVである。振動・confidence・途絶の長時間試験は、機能だけを最短で通す今回の範囲外とする。
