**一行でいうと: MIT（モード8）で位置指令が通る。MIT 位置とサーボ角は同じカウンタ（`o 0` で両方0）。起動ごとに決まった姿勢で `o 0` が要る。実効Kp・実効Kd は機種ごとに同じ係数（AK80-9 0.523 / AK10-9 約 1.24）で効くので、機種別に割れば stiffness:damping 比が保てる。ただし「指令トルク単位 = 物理 N·m」かは機種で違いうる（Kt 未決）。電流は符号が信用できない。指令を止めてもトルクを出し続ける。**

## ★ 2026-09-22 の確定（0x1C・保存済みCSVの回帰。追加の実機送信なし）

根拠: `logs\\d9_one_axis_0x1c.csv`（402行）と `logs\\d9_static_probe_0x1c.csv`（401行）。どちらも軸は完全に静止しているので、指令した位置誤差が正確に分かる。報告書 `reports/2026-09-22_d9-0x1c-current-vs-error.md`。

**MIT の Kp 欄は「位置誤差 1 rad あたりの電流[A]」として効く。機種による係数は掛からない。**

```
|電流[A]| = Kp_cmd × |位置誤差[rad]|
実測: 8.20 A/rad と 8.31 A/rad（指令 Kp 7.937、比 1.03 / 1.05、切片 0.02 A 未満）
```

- 2026-09-17 夜の「ゲインは機種によらず電流で出ている」の定量版。c_p（AK80-9 0.523 / AK10-9 1.258）は**その機種のトルク指令欄の目盛り[N·m/A]**とほぼ同じ意味になる（AK80-9 の実測 `KT_CMD` 0.59 と整合）。
- 物理トルクは `電流 × Kt` であり、**Kt は AK10-9 で未測定**。だから Kt に依存しない量（電流・不感帯）で判断する。
- **不感帯 = 動き出し電流 ÷ Kp_cmd（Kt 不要）。** 0x1C は 0.66 A を掛けても 1 LSB も動かないので、デプロイゲイン（指令 Kp 7.937）での不感帯は **4.8°以上**。
- 比較: 脚の付いていない単体の AK80-9 の動き出し電流は 0.63 A（2026-09-14、`actuator_params.md` §0）。**0x1C の 0.66 A はそれとほぼ同じで、異常を示す値ではない。**
- 判定手順は実機なしで再現できる: `ver9_d8_sender.py --analyze <csv>`（CANを開かない）。

### ここから言えること（デプロイ向け）

- **Kd の分離は決着。** どちらの機種も c_p ≈ c_d（比 1.00 / 1.03）。Kp・Kd を機種の係数で割ればシムの stiffness:damping 比が保たれ、実効 damping ×1.0。
  ```
  AK80-9: 指令Kp = stiffness / 0.523   指令Kd = damping / 0.523
  AK10-9: 指令Kp = stiffness / 1.258   指令Kd = damping / 1.216
  ```
- **ゲインは機種によらず「電流」で出ている**（\\|I\\|/(Kp·rad) が 0.94 / 0.97 で同じ）。機種で違うのはトルク指令の目盛り（2.3 倍）。**→ 「指令トルク単位 = 物理 N·m」かは機種ごとに違いうる。物理 stiffness が合っているかは Kt（未決1）で確かめる。** シムは stiffness ×0.7 が不合格帯なので後回しにしない。
- 09-16 の ID34 脚付き c_p 0.538 と 09-17 脚なし 0.523 は 3% 差（原点・負荷の違いの範囲）。
- Windows の 50 Hz 予定表は最大 23 ms（目安 25 以内）。送信・受信・推論を載せた 10 モーター分（D3）は未。

### ここから言えること（デプロイ向け）

- **原点手順: 起動 → フィードバックが来るまで待つ → 決まった姿勢（治具・吊り姿勢など）で `o 0` → 以後 MIT 位置 = その姿勢からの関節角。** offset は 0 として扱える。
  - 補助: 姿勢が ±40 deg 以内で分かっていれば、投入時の値を 80 deg 単位で直せる（AK80-9。AK10-9 の窓は確認中）。
  - MIT の位置レンジは ±12.56 rad（±720 deg）なので、`o 0` は可動域の中で打つ。
- **制御ループには「受信（または送信）が途切れたら零指令」を必ず入れる。** モーター側は脱力しない。
- **電流を観測・判定に使うときは大きさだけ。** トルクの向きは電流から読めない。
- **脚付きでは約 0.35 N·m の静止摩擦 → 実効Kp 15 でも約 1.4 deg の不感帯。**

## 非常停止の方針（2026-09-07 ユーザー決定）

- **非常停止＝電源を抜く（切る）。遠隔緊急停止は実装しない。**
- ソフトの `x` / Ctrl+C / 自動停止は「日常的に止める手段」。**モーターは指令が途切れても脱力しない（A4）ので、ソフトが落ちたら電源で止める。**

## 確定した通信仕様

- **フィードバック CAN ID = `(0x29 << 8) | ID`**（ID34 → `0x2922`、ID18 → `0x2912`）。拡張29bit、DLC=8。
- **フィードバックレート = 50.0 Hz ちょうど。** 何も送らなくても流れる（電源投入直後の数秒を除く）。公式マニュアル上は 1〜500 Hz で設定可能（上位機、未確認）。
  - 帯域は余裕あり。10モーターで 500フレーム/秒 ＝ 1Mbps の約 6.4%。
- **MIT で制御してもフィードバックはサーボ形式のまま。** MIT 専用の応答フレームは存在しない。

### 送信パケット（`(モード番号 << 8) | モーターID`・拡張29bit）

| モード | CAN ID (ID34) | 意味 | データ | 検証状況 |
|---|---|---|---|---|
| 0 | 0x022 | デューティー | int32 (比 × 100000) | 未検証 |
| 1 | 0x122 | 電流(トルク) | int32 (A × 1000) | **確定** |
| 2 | 0x222 | 電流ブレーキ | int32 (A × 1000) | 未検証 |
| 3 | 0x322 | 速度 | int32 ERPM | **確定** |
| 4 | 0x422 | 位置 | int32 (deg × 10000) | **確定**。過渡が乱暴 |
| 5 | 0x522 | 原点設定 | 1byte (0=一時/1=恒久/2=初期化) | **確定**。pos が 0.0 になる。**MIT 原点も同時に 0 になる**。ただし公式現行manualは`kind=1`をデュアルエンコーダ機種限定とする。AK80-9 V3.0はSingleなので、AK80では電源断後に保持されない。AK10-9（Dual）の保持精度は別途固定姿勢で検証する。 |
| 6 | 0x622 | 位置-速度 | int32 pos + int16 spd/10 + int16 accel/10 | **確定**（`jog`。AK10-9 でも 09-17 に使用） |
| **8** | **0x822** | **MIT制御** | **Kp→Kd→位置→速度→トルク** | **確定。位置指令も成功** |

### フィードバック（8バイト）

`data = pos(2) spd(2) cur(2) temp(1) err(1)`
pos = int16BE / 10 [出力軸 deg] ／ spd = int16BE × 10 [ERPM] ／ cur = int16BE / 100 [A] ／ temp = uint8 [℃] ／ err = uint8

- **★ cur は大きさだけ信用できる。符号は当てにならない。**
- **★ pos は電源投入時に 80 deg の窓へ折り返された値から始まる（AK80-9）。**
- err（公式 v3.0.0 42頁）: 0 なし / 1 モーター過温度 / 2 過電流 / 3 過電圧 / 4 低電圧 / 5 エンコーダ異常 / 6 MOSFET 過温度 / 7 モーターロック。

### ERPM ⇄ 出力軸角速度

```
ERPM = 出力軸[rpm] × 9 × 21 = 出力軸[rpm] × 189      出力軸[deg/s] = ERPM / 31.5
```
（**極対数 21 は 09-17 に AK80-9・AK10-9 とも確定**: ERPM 換算 / 位置の差分 = 0.999 / 1.000）

| **送信CAN ID** | `(8 << 8) \\| モーターID` の拡張29bit。ID34 → `0x822`、ID18 → `0x812` |
| **ペイロード順** | **Kp → Kd → 位置 → 速度 → トルク**（公式 v3.0.0 38頁） |
| **enable フレーム** | **不要** |
| **応答** | サーボ形式 `0x29xx` の 50Hz 定期 |
| **位置の座標** | **サーボ角と同じ（`o 0` で両方0、電源を越えても一致）** |
| **指令途絶** | **最後の指令を出し続ける（A4）** |

### ビット配置

```
byte0: Kp 上位8
byte1: Kp 下位4 | Kd 上位4
byte2: Kd 下位8
byte3: 位置 上位8
byte4: 位置 下位8
byte5: 速度 上位8
byte6: 速度 下位4 | トルク 上位4
byte7: トルク 下位8
```

**Kp=Kd=0 なら位置・速度の欄が何であってもモーターは無視する＝零指令が無害。**

### ⚠ 旧 A8「ext を送るとバスが落ちる」の真因

classic MIT 並びで「位置 0 rad」を送ると `0x7FFF` が先頭に来て **Kp=250 / Kd=4.84** と読まれ **48.7 A**。過電流保護でバスが落ちていた。

### ver8 `morg` の原理

`|I| = k × |(X − θ_servo) − offset|`（静止中は電流＝指令トルク/内部定数なので摩擦に依存しない）。
① Kp=1LSB で |I| からずれの大きさ e を出し、offset±e の両側を試して小さいほうへ寄せる → ② Kp 0.24（R² ≥0.6）、③ Kp 0.98（R² ≥0.8）でそれぞれ9点振って V字を当てる → ④ offset±0.15 rad の |I| の左右差で検証。
雑音は √(m² − σ²) で補正。

### ゲインの読み替え（sim-to-real）

```
AK80-9: 指令Kp = stiffness / 0.523   指令Kd = damping / 0.523   （stiffness 15 → 28.7、damping 1.5 → 2.87）
AK10-9: 指令Kp = stiffness / 1.258   指令Kd = damping / 1.216   （stiffness 15 → 11.9、damping 1.5 → 1.23）
いずれも「指令トルク単位」。物理 N·m への換算は Kt（未決1）。ver8 の Kp 上限 20 は AK80-9 のシム値に届かない可能性
```

### ⚠ Kt は機種ごとに要る

`brk` の実測で 0.28 N·m → 0.475 A、0.30 N·m → 0.506 A（AK80-9）。きれいに 0.59 が出るが、モーターが「指令トルク ÷ 内部定数」で電流を決めているだけの可能性。**09-17: ゲイン由来のトルクは機種によらず同じ電流（0.94 / 0.97 A per Kp·rad）で、トルク指令の目盛りは 2.3 倍違う。** 物理 N·m との対応は重り＋棒で外から測るしかない。

## 挙動の解釈（誤解しやすい点）

- **原点設定（モード5）はモーターを動かすコマンドではない。** 今いる物理位置を 0 と定義し直すだけ。
- **電源投入時の角度は物理角ではない。** 80 deg の窓に折り返された値（AK80-9）。
- **静止摩擦と動摩擦は別。** Isaac Lab の `friction` に入れるのは動摩擦。
- **トルク指令は無負荷で暴走する。** 静止摩擦を超えた瞬間に 270 deg/s まで加速した。
- **位置指令は静止摩擦の不感帯で止まる。** 定常偏差 ≈ 静止摩擦 / 実効Kp。
