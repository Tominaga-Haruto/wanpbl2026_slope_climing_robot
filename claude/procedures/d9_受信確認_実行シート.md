# D9-0 実行シート: 吊り支持で両CANの受信だけを確認する

> 実験中は上から順に一項目ずつ進める。各停止点で異常があれば、その場で先へ進まず主電源をOFFにする。
>
> **今回の到達点:** 吊り支持中に、ch=0 と ch=1 の合計10軸のフィードバックを受信して終了する。**CAN送信数は0**。
>
> **今回しないこと:** 原点設定、MIT指令、位置指令、トルク指令、方策、ONNX、T265、コントローラー。D9全体の完了判定や関節を動かす試験にも進まない。

この実行シートは、正本の [procedures/d9_仮_吊りCAN統合_実験手順.md](procedures/d9_仮_吊りCAN統合_実験手順.md) の最初の安全停止点を、実験者が使う粒度に分解したものである。判断が食い違う場合は正本を優先する。

---

## 0. 実験開始前に理解すること

- CANに**送信する**操作は一切しない。
- `scan 3` は3秒間、両CANチャネルからフィードバックを**受信するだけ**である。
- `q` はコンソールを閉じるだけで、CANへは送信しない。
- コンソールでは `scan 3` と `q` 以外を入力しない。特に `o ...` は原点設定を送るため、今回は絶対に入力しない。
- 異常時にPC上の操作で復旧しようとしない。**最初に主電源をOFF**にする。ソフトウェアは非常停止ではない。

### 今回の合格条件

1. 支持具が、手を離しても安定している。
2. ch=0/ch=1の合計で10軸すべてが一意に表示される。左右の固定chは判定しない。
3. 全軸で `err=0`、かつ `age` が `0.3 s` 以下である。
4. 異音、機体や支持具のずれ、ケーブルの張り・接触がない。
5. 入力したコンソール命令が `scan 3` と `q` だけである（送信数0）。

---

## 1. 通電前の安全確認

ここは**主電源OFFのまま**行う。

### 1-1. 支持を確認する

1. ロボットが床から完全に離れていることを確認する。
2. 棒または治具がロボットの重量を支え、手を離しても落下・回転・ずれがないことを確認する。
3. 手で支えるだけの状態なら、今回の実験は開始しない。
4. 脚、足先、胴体、T265、CANケーブル、電源ケーブルが支持具に当たっていないことを確認する。
5. ケーブルが引っ張られていないこと、可動しそうな箇所に引っ掛かっていないことを確認する。

### 1-2. 非常停止と記録を準備する

1. 主電源がOFFであることを指差し確認する。
2. 主電源スイッチに、電源遮断担当者がすぐ手を届かせられる位置を取る。
3. 可能なら、PC操作担当者と電源遮断担当者を分ける。
4. 正面、左側面、右側面から支持状態を撮影する。
5. 写真を撮ったら、支持具に触れずにロボットを10秒観察する。ずれや回転があれば中止する。

### 1-3. D7の条件を確認する

次のどれかに該当するなら、D9-0を始めず、D7を基準姿勢から再実施する。

- D7の原点設定後に部品を脱着した。
- 配線を変更した。
- 原点設定時の基準姿勢から関節を回した。

該当しなければ、次へ進む。

### 1-4. PCとUSB2CANを準備する

1. USB2CANをノートPCへ接続する。
2. ノートPCでPowerShellを開く。
3. まだコンソールを起動せず、下の場所にスクリプトがあることだけを確認する。

**ノートPCのPowerShellで実行する。**

```powershell
Test-Path C:\Users\harut\Connect2USB2CAN\d7_origin_console.py
```

4. 結果が `True` なら次へ進む。`False` なら通電せずに止まり、その表示を報告する。

### 1-5. 通電前の最終チェック

下の全項目を声に出して確認し、すべてにチェックできるときだけ通電する。

- [ ] 主電源はOFFである。
- [ ] 機体は床から離れ、治具または棒だけで安定している。
- [ ] 手で支えていない。
- [ ] 支持具・脚・ケーブル・T265が接触または干渉していない。
- [ ] 電源遮断担当者が主電源に届く。
- [ ] D7後に姿勢・部品・配線を変えていない。
- [ ] USB2CANがノートPCに接続されている。
- [ ] `Test-Path` の結果が `True` だった。
- [ ] 今回入力するコンソール命令は `scan 3` と `q` だけだと確認した。

一つでも未チェックなら、ここで止める。

---

## 2. 通電して、受信だけを確認する

### 2-1. 通電直後

1. 電源遮断担当者が主電源のそばにいることを確認する。
2. 主電源をONにする。
3. PCには触らず、ロボットと支持具を3秒間見る。
4. 異音、振動、支持のずれ、ケーブルの張り、警告表示が**一つでも**あれば、直ちに主電源をOFFにする。この回は終了する。
5. 異常がなければ、次へ進む。

### 2-2. コンソールを起動する

**ノートPCのPowerShellで実行する。1行ずつ実行する。**

```powershell
cd C:\Users\harut\Connect2USB2CAN
```

```powershell
py -3.13 d7_origin_console.py
```

画面に入力案内が出るまで待つ。ここでは何も入力しない。

起動エラーが出た場合は、主電源をOFFにして終了する。エラー全体ではなく、赤字の先頭から最後までをスクリーンショットで残す。

### 2-3. 受信を開始する

コンソールの入力待ち行が表示されたら、次の1行だけを入力してEnterを押す。

```text
scan 3
```

3秒間待つ。待っている間も、ロボット、支持具、ケーブルに異常がないか見る。

`scan 3` の出力が最後まで表示されたら、画面全体のスクリーンショットを撮る。次の項目で判定するまでは、追加のコンソール命令を入力しない。

---

## 3. 画面を見て判定する

### 3-1. 出力に含まれるべき10軸

| ch | H関節 | ID | 機種 |
|---:|---|---:|---|
| 0 | LL_HR | `0x1C` | AK10-9 |
| 0 | LL_HAA | `0x11` | AK10-9 |
| 0 | LL_HFE | `0x21` | AK80-9 |
| 0 | LL_KFE | `0x1A` | AK10-9 |
| 0 | LL_FFE | `0x2B` | AK80-9 |
| 1 | LR_HR | `0x13` | AK10-9 |
| 1 | LR_HAA | `0x1B` | AK10-9 |
| 1 | LR_HFE | `0x2A` | AK80-9 |
| 1 | LR_KFE | `0x12` | AK10-9 |
| 1 | LR_FFE | `0x22` | AK80-9 |

### 3-2. 行ごとの確認

出力を上の表と照らし、各行について次を確認する。

- IDが表にあり、10台すべてが一度以上表示された。
- chが表と一致する。
- `err=0` である。
- `age` が `0.3 s` 以下である。

### 3-3. 失格時の手順

次のいずれかなら失格である。

- 1台でも見つからない。
- 未登録IDが表示される。
- `err!=0` がある。
- `age > 0.3 s` がある。
- 異音、振動、支持ずれ、ケーブル干渉がある。
- `scan 3` 以外の命令を誤って入力した、または入力する必要が出た。

失格なら、この順で行う。

1. **主電源をOFFにする。**
2. 主電源がOFFになったことを確認する。
3. コンソールには追加操作をしない。画面が残っていればスクリーンショットだけを撮る。
4. 下の「5. 結果を送る」のテンプレートで、`失格` として報告する。
5. 原因調査や再試行は、この報告への返答を待ってから行う。

### 3-4. 合格時の手順

10台すべてが表どおりで、全行 `err=0`、全行 `age <= 0.3 s`、かつ物理的な異常もなければ合格候補である。

1. コンソールに次の1文字だけを入力してEnterを押す。

```text
q
```

2. PowerShellの通常の入力待ちに戻ったことを確認する。
3. 主電源をOFFにする。
4. 主電源がOFFになったことを確認する。
5. これで今回の実機操作は終了。**次のコマンドや次段階の操作はしない。**

---

## 4. ログを見つけて保存する（通電後、主電源OFFのまま）

**ノートPCのPowerShellで実行する。これはログ一覧を表示するだけである。**

```powershell
Get-ChildItem C:\Users\harut\Connect2USB2CAN\logs\d7_origin\session_*.txt | Sort-Object LastWriteTime -Descending | Select-Object -First 3 FullName,LastWriteTime,Length
```

1. 表示された先頭行の `FullName` を控える。
2. そのログを削除・移動・編集しない。
3. `scan 3` のスクリーンショットと、支持状態の写真をこのログと同じ実験記録として保管する。

---

## 5. 結果を送る

下をコピーし、`[]` の中だけを埋めて送る。出力が長ければ `scan 3` の画面スクリーンショットでもよい。

```text
D9-0 結果: [合格 / 失格]
支持: [手放しで安定 / 不安定]
ch=0: [5軸すべて / 不足あり: ID]
ch=1: [5軸すべて / 不足あり: ID]
err: [全軸0 / 異常あり: IDと値]
age: [全軸<=0.3 s / 異常あり: IDと値]
未登録ID: [なし / あり: ID]
異音・支持ずれ・ケーブル干渉: [なし / あり]
コンソールに入力したもの: [scan 3, q / 実際の入力]
ログの絶対パス: [C:\Users\harut\Connect2USB2CAN\logs\d7_origin\session_....txt]
```

## この後の境界

D9-0に合格しても、MIT送信・位置目標・トルク・方策には進まない。次は、送信器の実装と乾式レビューを別の停止点として行い、ユーザーが明示してから初めて **1モーター → 片脚 → 全身（吊り）** の順に進める。
