# D10-10: 吊り紐を付けたまま、足を床に着けて立たせる（方策なし → vx 0 の方策）

> 作成 2026-09-23。根拠は `../reports/2026-09-23_d10-9_result.md`（足の接触角）と `../reports/2026-09-23_d10-8_result.md`（吊りではこれ以上分からない）。
> 送信器 build **`D10_10_FLOORSTAND_20260923_1600`**（`.bak_20260923_floorstand` あり、テスト 143本 OK）。
> 異音・接触・支持ずれ・エラー・中止表示・転倒しかけたら、PC を操作する前に**主電源を切る**。**吊り紐は最後まで外さない。**

## なぜやるか

- 吊ったままでは、歩く指令（vx 0.2）の方策は空中で脚を漕ぐだけで、これ以上分かりません（D10-8 判定2）。方策が学習したのは、足が床に着いて体重を支えている状態です。
- 床に着けると、KFE・FFE に吊りのときより大きな電流が要ります。今の `--gravity-limits`（KFE 3.0 A / FFE 2.0 A）では、立っただけで中止する見込みです（下の推定）。
- そこで、**まず方策なしで立たせて、荷重時の保持電流を実測します（R1）**。そのあと **vx 0 の方策を 5 s**（R2）。歩かせる（vx > 0）のは次の段階です。

## 何が変わったか

1. **`--floor-limits` を追加しました。** `--gravity-limits` の表のうち、**KFE と FFE だけを 6.0 A に上げたもの**です。ほかは同じです（HR 3.0 / HAA 6.0 / HFE 11.0 A）。
   - 根拠は URDF（10.1 kg）から計算した、両足で立つときの静的な必要電流です。初期姿勢とシムの平均歩行姿勢、足圧中心が足首の真下／5 cm 前、で計算しました: HR ≤0.1 A、HAA ≤3.5 A、HFE ≤9.1 A、**KFE ≤3.9 A、FFE ≤4.7 A**。KFE・FFE はこれの約 1.5 倍です。
   - これは最初の1回のための値です。**次からの表は R1 の実測から決めます。**
   - `--gravity-limits` とは一緒に使えません。`--haa-close-deg`・`--sign-pose` とも一緒に使えません。
2. **`--floor-limits` のときだけ、`--stand-seconds` を 30 s まで伸ばせます。** 初期姿勢で保持しているあいだに、吊りを下ろして足に荷重を移すためです。
3. **5 s より長い保持では、2 s ごとに電流を表示します。**
   - 例: `STAND HOLD   12/30s: max|I| L/R HAA 0.6/0.3A, HFE 2.1/1.9A, KFE 2.4/2.2A, FFE 1.1/0.9A`
   - 吊りを下ろすと HFE・KFE の値が上がるので、荷重が乗ったことが分かります。
4. 変えていないもの: 速度中止 100°/s、stale、原点 45°、Kp/Kd、関節符号、slew の上限 60°/s、`--duration` ≤5 s。

## 吊り方（毎回）

- 吊り紐は付けたままにします。**紐のたるみは 2〜3 cm 以内**にします。倒れかけたら、膝や胴が床に着く前に紐が止める長さです。
- 原点を取るとき（脚をまっすぐ下ろした姿勢）に、**足裏が床から約 3 cm 浮く高さ**にします。
  - URDF では、初期姿勢へ移ると足首が約 1 cm 上がります。なので、ramp のあいだ足は床に着きません。
- 吊りを下ろす担当、主電源の担当、動画の担当を分けます。
- 床は平らで滑りにくいところにします。T265 の前に物を置かないでください。

## 共通の事前条件（毎回）

1. 上の「吊り方」の高さで吊ります。電源を切る担当が主電源に手を置いておきます。
2. 電源は片脚に1台ずつつなぎ、GND を共通にします。電流制限のつまみは最大にします。**各 run で電源の電流表示の最大値を記録します（まだ一度も記録がありません。床上では必須）。**
3. `scan 3` → 基準姿勢で脚を持ったまま `oa` → `scan 3` で全軸 `+0.0deg` を確認します。
4. `oa` のあと、**脚を基準姿勢で持ったまま起動します**（D10-9 R2 では脚が垂れた状態で起動していました）。最初の `RAMP progress: 0/10s` で手を離します。
5. 起動した直後の行を確認します。
   - `ver9_d8_sender build=D10_10_FLOORSTAND_20260923_1600`
   - `JOINT SIGNS`（5軸が −1）
   - `FLOOR LIMITS: ... KFE=6.0A ... FFE=6.0A`
6. 横から動画を撮ります（足と胴の傾きが見える向き）。
7. CSV の名前は run ごとに変えます。電源を切ったら、手順3からやり直します。

## R1: 初期姿勢で立たせて、荷重時の保持電流を測る（方策なし・要承認・動画）

```powershell
cd C:\Users\harut\Connect2USB2CAN; .venv310\Scripts\python.exe ver9_d8_sender.py --arm --all-axes --floor-limits --stand-seconds 30 --stand-only --package C:\Users\harut\wanpbl2026_slope_climing_robot\H_eff13p5_2999\H_eff13p5_2999 --ramp-seconds 10 --csv logs\d10_10_r1_floor_stand_a.csv
```

進め方:

1. ramp（10 s）は空中で行います。
2. `STAND HOLD: holding ...` が出たら、**0〜15 s のあいだに吊りをゆっくり下ろします。**
   - 足裏が床に着き、紐が 2〜3 cm たるむまで下ろします。
   - 下ろしながら `STAND HOLD .../30s` の HFE・KFE・FFE の値を見ます。荷重が乗ると上がります。
3. **15〜30 s は吊りを動かさず、荷重を乗せたままにします。** 最後の 7.5 s がそのまま保持電流の測定値（`HOLD POSE RESULT`）になります。
4. どれかの値が **5 A を超えたら**、吊りを少し上げて荷重を戻してください（中止値は 6 A です）。
5. 30 s で `STAND ONLY: ... zero MIT` が出ると、脚の力が抜けて紐に落ちます（2〜3 cm）。**表示が出てから**胴を手で支えます。
