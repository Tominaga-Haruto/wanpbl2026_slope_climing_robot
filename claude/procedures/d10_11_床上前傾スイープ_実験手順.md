# D10-11: 床の上で前傾を少しずつ足して、立てる前傾を測る → その姿勢から方策（vx 0）

> 異音・接触・支持ずれ・エラー・中止表示・転倒しかけたら、PC を操作する前に**主電源を切る**。**吊り紐は最後まで外さない。**

## なぜやるか

- D10-10 では、床に降ろすと初期姿勢でも方策でも後ろへ倒れました。足首はつま先が上がる向きに 5〜9°押し戻されていて、かかとに乗っています。
- URDF では、初期姿勢の重心は足首より 1.5 cm 前にあります。膝を伸ばしても 1.0 cm 前で、ほとんど変わりません。**実機の重心がモデルより後ろにある**と考えています（T265・配線など。未測定）。
- そこで、**体を少しずつ前へ傾けて、足首が押されなくなる角度（重心が足首の真上に来る角度）をログで測ります。** 膝の曲げも2通り（K=20 と K=10）で比べます。
- 最後に、その姿勢から vx 0 の方策を回します。

## 何が変わったか

1. **`--stand-knee-deg K`（0〜30）:** 初期姿勢を HFE −K/2、KFE +K、FFE −K/2 にします。足裏は胴と平行のままです。K=20 が今までの初期姿勢です。
2. **`--stand-lean-deg L`（−5〜+8）:** 両 FFE の目標に L°を足します。+ はつま先を下げる向きです。足裏が床に着くと、**体全体が L°前へ傾きます。**
3. **`--lean-sweep-deg M`（0〜10、`--floor-limits --stand-only` 専用）:** 流れは次のとおりです。
   - 保持のあと、両 FFE に前傾を 0.5°/s で M°まで足す
   - M°で 3 s 保持
   - 1°ごとに、足首のずれ（目標 − 実際）と電流を表示
   - `BALANCE LEAN: +x.xdeg` を出す（ずれが + から − に変わる角度。重心が足首の上に来る角度）
   - ずれが + なら「かかとに乗っていて後ろへ倒れる向き」、− なら「つま先に乗っていて前へ倒れる向き」です。
4. 判定には電流ではなく位置のずれを使います。AK80-9 の CSV の電流は、符号が当てになりません（D10-10 報告）。
5. 変えていないもの: `--floor-limits` の表（KFE・FFE 6.0 A）、速度中止 100°/s、stale、原点 45°、Kp/Kd、関節符号、slew の上限 60°/s、`--duration` ≤5 s。

## 吊り方と支え方（毎回）

- 吊り紐は付けたままにします。降ろしたあとのたるみは 2〜3 cm にします。
- 原点を取る姿勢（脚をまっすぐ）で、足裏が床から約 3 cm 浮く高さにします。
- **支えるのは左右からだけにします。前後には手を添えず、倒れかけたときだけ受けます。** 前後に支えると、測りたい釣り合いが手の力で消えます。
- 前傾スイープの後半は前へ倒れる向きになります。**前側にも受ける人を置きます。**

## 共通の事前条件（毎回）

1. **ねじの確認。** 全モーターの取り付けねじが締まっているかを確かめます。D10-10 では 0x11・0x1B・0x2B がかなり緩んでいました。
2. 上の高さで吊ります。電源を切る担当が主電源に手を置いておきます。
3. 電源は片脚に1台ずつつなぎ、GND を共通にします。電流制限のつまみは最大にします。**各 run で電源の電流表示の最大値を記録します（まだ一度も記録がありません）。**
4. `scan 3` → 基準姿勢で脚を持ったまま `oa` → `scan 3` で全軸 `+0.0deg` を確認します。
5. 脚を基準姿勢で持ったまま起動します。最初の `RAMP progress: 0/10s` で手を離します。
6. 起動した直後の行を確認します。
   - `ver9_d8_sender build=D10_11_LEANSWEEP_20260923_1700`
   - `JOINT SIGNS`（5軸が −1）

7. **横から動画を撮ります**（前後の傾きが見える向き）。**画面ログは全文コピーします**（D10-10 は中止理由が画面にしか残っていませんでした）。
8. CSV の名前は run ごとに変えます。電源を切ったら、手順4からやり直します。
