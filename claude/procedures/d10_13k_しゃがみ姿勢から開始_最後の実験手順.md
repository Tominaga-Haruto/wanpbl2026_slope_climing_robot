# D10-13K（最後の実験）: 歩くときに近いしゃがみ姿勢から始め、膝の逆折れと足の衝突を指令側で防ぐ

> 作成 2026-09-24。送信器 build **`D10_13K_CROUCH_20260924`**（`.bak_20260924_crouch`、テスト 197本 OK）。
> モーターは下から 1 = 足首、2 = 膝、3 = 股の前後、4 = 股の開閉、5 = 股のひねり。
> 異音・接触・暴れたら、PC を操作する前に**主電源を切る**。**吊り紐は最後まで外さない。**

## 何を直したか（気に入らなかった点ごと）

| 気に入らなかった点 | 原因（ログ・シムで確認） | 直し方 |
|---|---|---|
| 始まった瞬間、下から2番目（膝）をピンと伸ばして暴れる | シムは毎回、空中から落として始める。方策の最初の動き（膝を伸ばす）は着地の動き。**シムの初期姿勢で止まって立っていると、ONNX は膝 −0.84 / −0.59 を出す** | **`--start-pose crouch`:** シムで歩いているときに近いしゃがみ姿勢で立たせてから始める（初期姿勢から下から4番目 −6°、3番目 +6°、2番目 +13°、1番目 −19°）。同じ ONNX で膝の最初の出力は **−0.07 / +0.04** に下がる。足裏と胴の平行は変わらない（3つの関節の合計は同じ） |
| 下から2番目がまっすぐより逆へ折れる（G で 10〜12°、J で 47°） | シムの URDF に膝の可動域がない | **`--safe-clamp`:** 方策の膝の指令を、まっすぐの 2°手前で止める |
| 左右の足がぶつかる | シムは下から4番目 −15°で歩くが、実機は −8.5〜−11°で足が当たる | **`--safe-clamp`:** 下から4番目の指令を −8°までに止める |
| 下から2番目の補正 | G で、床の上の関節角と T265 が −3 / −2°まで合った | そのまま使う（`--knee-trim-deg 19 16`） |
| 方策の始まりで歩けと言っていない | シムは始まった瞬間から指令がある。指令 0 で立っていると、ONNX は足首を強く踏む（+0.8〜0.9） | **最初から vx 0.3**（待ちなし）。同じ ONNX で足首の最初の出力は −0.2 / −0.3 に下がる |
| 角度で止める設定 | J で外したら、膝が逆に 47°折れて CAN が落ちた | 元に戻す（立ち姿勢から 45°・膝の逆折れ 10°）。指令側の止め（上）が先に効く |

変えていないもの: 傾き 30°の中止、止まったあとの 3 s 保持、電流・速度の中止、直立ゲート ±5°、ゲイン ×1.0、slew 200°/s。
