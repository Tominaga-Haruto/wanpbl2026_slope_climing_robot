# D9-3: 0x1C 1軸ブレークアウェイ probe 実験手順

> **最新は末尾の追記（2026-09-22）。実施済み・判定C・この要求角での再実行は不可。**
> 作成 2026-09-22（ユーザー承認済み）。**対象は 0x1C（LL_HR）1軸だけ。** 片脚・全身へは進まない。
> 異音・接触・支持ずれ・エラー・表示された中止のときは、PC操作より先に**主電源OFF**。
> 根拠: `../reports/2026-09-22_d9-0x1c-current-vs-error.md`。旧 D9-2 は `../d9_2_1軸MITランプ_実験手順.md`（この手順に置き換わった）。

## 何をする実験か（1段落）

0x1C は「MITが効いていない」のではなく、**要求角が自分の不感帯より小さかったから動かなかった**ことが分かった。`電流 = 指令Kp × 位置誤差` なので、要求角を大きくすることは「掛ける電流を大きくすること」と同じである。0.66 A では動かなかったので、**0.90 A まで掛かる −6.5° を1回だけ**送って、普通のスティクションなのか機構の異常なのかを分ける。ゲイン（Kp・Kd）もトルク欄も電流中止（1.0 A）も変えない。

## 事前条件

1. **先に無通電の機構確認**（主電源OFF・吊り支持のまま）。0x1C から先のリンク・スペーサ・ケーブル・支持具の接触、締結、**手で回したときの引っ掛かり**を写真／動画に残す。減速機ぶんの重い手応えは正常。引っ掛かりや干渉があれば、直してからこの手順に戻る。
2. 機体は吊り支持済み。**電源遮断担当が主電源に手を置く。**
3. 通電後、D7 コンソールで `scan 3` を行い、全10 IDの受信と `err=0` を確認する。
   - static probe は 0x1C への相対指令なので、**そのためだけの `oa`（全軸原点）は不要**。
   - ただし送信器は全10軸のフィードバックを見ており、**どれかが原点から 45° を超えてずれていると `origin/pre-arm pose abort` で止まる。** その場合だけ、同じ通電中に D7 の `oa` を行ってからやり直す。

## 中止

`motion/current abort`（電流1.0 A／速度100°/s）、`stale feedback`、`motor error`、`origin/pre-arm pose abort`、異音、接触、支持ずれ ── いずれも**主電源OFF**。再試行しない。終了時は零MITが自動で送られる。

## 事前に決めた判定（走らせる前にここを読む。走らせた後に基準を変えない）

`STATIC PROBE:` 行の「max feedback movement」と「max |current|」、`TORQUE PATH:` 行、`DEADBAND:` 行で読む。

| | 条件 | 意味 | 次にやること |
|---|---|---|---|
| **A 合格** | 移動 ≥ 3.25°（要求の50%） | 普通のスティクション。0x1Cは正常 | 動き始めた行の `|電流|` が**動き出し電流**。不感帯 = それ ÷ 7.937 を報告書へ。片脚へ進む前に、この不感帯で方策が成立するかを判断する |
| **B 部分** | 0.1° ≤ 移動 < 3.25° | 動き出しはした。異常ではない | Aと同じく動き出し電流を読む。値が取れているので**再試行しない** |
| **C 不動** | 移動 < 0.1°、かつ `TORQUE PATH: verified` | 0.90 A でも動かない＝**機構の異常に確定** | 主電源OFF。ゲインを上げない。機構（干渉・締結・ケーブル・支持具）を直す。直らなければ 0x1C を外して単体で測る |
| **D 経路異常** | `TORQUE PATH:` が `absent` か `anomalous` | 今回の前提（電流=Kp×誤差）が崩れている | 主電源OFF。電気・通信側の調査へ戻る。機構を触らない |

**Cのときに要求角をさらに上げない。** Kp 7.937 では 6.86° で電流中止 1.0 A に当たるので、この方式で探れるのはここまでである（送信器が角度を拒否する）。それ以上は、Kp=0・トルク欄ランプ（最初の 0.1° で即停止）という別設計になり、**別途レビューしてから**行う。

## 追記（2026-09-22）: 実施済み・判定 C・この手順での再実行は不可

**この手順は 2026-09-22 約19:59 JST に1回実施し、判定 C（不動）で終わっている。結果は `../reports/2026-09-22_d9-3_result.md`。** 以下はこの手順書の記述を上書きする。

1. **判定表の B（0.1° ≤ 移動）は使わない。** 0.1° はフィードバックの量子化1目盛で、ブレークアウェイと弾性たわみ・バックラッシュ・量子化ディザを区別できなかった。**ブレークアウェイの線は「目標へ向かう正味かつ持続した変位が 0.5°（5目盛）以上」**に改めた。実測の 0.200°（−0.4↔−0.5 を往復して −0.6 で静止）はこれを満たさず、判定は C である。基準を走らせた後に動かした件は報告書に明記した。
2. **読む行が増えた。** `STATIC PROBE:` は「max feedback movement」ではなく **net sustained movement**（正味・持続変位）と最大振れ幅の両方を出す。`DEADBAND:` は**保持電流**から出す（ピーク1サンプルは使わない）。最後に **`VERDICT: D9-3 <A|B|C|D>` の1行**と次の一手が出る。
3. **動かないことは実行時エラーではなくなった。** 旧ビルドは `RuntimeError: static probe abort` とトレースバックで終了していた。これは測定結果であって失敗ではない。現ビルドは判定行を出して終了コード（A/B=0、C=2、D=3）で返す。`motion/current abort`・`stale feedback`・`motor error`・`origin/pre-arm pose abort`・`repeat-probe abort` は従来どおり例外で止まる。
4. **同じ要求角での再実行はできない。** 実証された不動電流が 0.66 → 0.86 A に上がったため、送信器は要求角 −6.5° を `repeat-probe abort` で**電源を入れる前に**拒否する。Kp 7.937 で許される最大角は 6.64°（指令 0.92 A、電流中止 1.0 A から電流ノイズ 0.08 A を引いた値）で、新しい情報はほぼ取れない。
5. **次は `../handoffs/inactive/2026-09-22_d9-4_無通電機構確認.md`。** 主電源OFFでの機構確認である。ゲイン・目標角・トルク欄・電流中止を上げて先へ進まない。

現ビルドは `D9_VERDICT_20260922_2015`。冒頭の `ver9_d8_sender build=...` で確認する。
