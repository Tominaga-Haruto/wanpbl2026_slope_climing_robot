# D10-13E: 原点の中止を立ち姿勢から測り、転倒は傾きで止める。ゲイン ×1.0 と ×0.7 を交互に比べる

## なぜ

- D10-13D の R3 は、前へ 14°倒れかけたあと**自分で +1°まで立て直し、右脚を踏み出したところ**で止められました。
  - 止めたのは「原点 45°」の中止です。`--zero-offset cad_fk` では立ち姿勢そのものが膝 27〜32°にあるので、膝はあと 13〜18°しか曲げられませんでした。**転倒ではなく、普通の振り出しで止めていました。**
- 方策は毎回、最初の 0.3 s で前へ 14〜25°倒れ込みます（4 run とも同じ動き）。
  - 実機のトルクがシムより強い（Kt の仮説）なら、ゲインを下げると倒れ込みが小さくなるはずです。
- R1（補正した保持だけ）は 20 s 立ちました。`--zero-offset cad_fk` は続けて使います。

## 何が変わったか

1. **`--origin-ref stand`:** 原点 45°を、D7 原点ではなく**立ち姿勢（シムの既定姿勢）から**測ります。
   - 残す歯止め: D7 原点から 75°、膝がまっすぐより 10°以上逆に折れたら中止。
   - 中止の文面は「`+xx deg from the stand pose`」になります。
2. **`--tilt-abort-deg 30`（`--origin-ref stand` のとき必須）:** 方策の段階で、T265 の pitch か roll が 30°を超えたら中止し、3 s その場で保持します。
   - D10-13D で本当に倒れていた R4 は 0.46 s で 30°を超えていたので、ここで止まります。R3 の最大は 14°なので止まりません。
3. **`--policy-gain-scale 0.7`:** 方策の段階だけ Kp・Kd を ×0.7 にします。保持・ゲート・中止後保持は ×1.0 のままです。
   - 起動時に `POLICY GAIN SCALE planned: Kp/Kd x0.7`、方策開始時に `POLICY GAIN SCALE: Kp/Kd x0.7 from now` が出ます。
4. `--analyze` に `POLICY START:` の 1 行を足しました（方策の長さ、0/0.1/0.2/0.3/0.5/1.0 s の pitch、0.5 s までの最大、そこから戻った値）。判定はこの行で行います。
5. 変えていないもの: 電流中止の表、速度中止 400°/s、slew 200°/s、stale、関節符号、直立ゲート ±5°、`--fine-timer`、中止後保持 3 s。

## 吊り方と支え方（D10-13D と同じ）

1. ramp 10 s は空中。**ramp が終わるまで床に着けない。**
2. 保持のうちに吊りを降ろし、足裏を床に平らに着ける。
3. 胴を左右から手で起こし、`START GATE: pitch ...` を **0〜−3°（ほんの少し後ろ）** に合わせる。
   - D10-13D で一番早く倒れたのは、前 +2.8°で始めた R4 でした。前寄りでは始めないでください。
4. `START GATE open` が出たら、**両手を同時に 1〜2 cm 離す**。紐は 2〜3 cm たるませる。
5. **方策が始まったら Ctrl-C は押さない。** 倒れかけたら手と紐で受けるだけ。中止が出たら 3 s の保持中に胴を受ける。本当に危ないときは主電源。
6. 歩き始めたら吊り点ごと前へ動かす。

## 判定（run のあとで基準を変えない）

`POLICY START` の「peak |pitch| in 0.5s」を A 2 本・B 2 本で比べます。

| | 所見（ログ） | 次 |
|---|---|---|
| **1** | B の 2 本とも peak ≤ 8°、A の 2 本とも ≥ 14° | 実機のトルクが強すぎる（Kt の仮説）を支持。×0.7 を標準にし、分銅で Kt を測る。学習側は stiffness の DR を検討 |
| **2** | A と B の peak の差が 4°以内 | ゲインは主因でない。倒れ込みは方策の始め方そのもの。WRS 実験14 の S0 を待ち、シムでも同じなら「立った静止から始まる」学習（開始時の関節ランダム化の見直し）へ |
| **3** | 1 と 2 の間 | ゲインは一部効く。×0.7 で E5 まで進み、Kt を測る |
| **4** | どれかが 3 s 以上続く（倒れかけを手で受けたのは可） | E5 へ |
| **5** | E5 が 15 s 続き前へ進む | D10-14（長く・速く・手を外す）→ D10-15 → D11 |
| **6** | 傾き中止（`tilt abort`）が 0.5 s 以内に出る | 転倒。中止の時刻と軸を報告。**閾値は上げない** |
| **7** | 原点の中止（`from the stand pose` か `backstop` か `past straight`） | 軸と値を報告。既定姿勢から 45°動いたのは暴れ。これ以上は緩めない |
| **8** | `MIT send failed` / `CAN route discovery failed` | 主電源を切って中断。電源の表示・何をして戻したかを報告。電源の電流を測るまで次へ進まない |
