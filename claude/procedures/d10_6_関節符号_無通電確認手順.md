# D10-6: 全10軸の実機→H 符号を無通電（受信のみ）で確かめる

> 作成 2026-09-23。根拠 `../reports/2026-09-23_d10-5_result.md`。**MIT は1フレームも送らない。** D7 コンソールの `scan` だけを使う。

## 目的

D4 は全軸の符号を +1 とした。シムの URDF では HFE・KFE・FFE の軸が左右とも同じ向きなので、鏡像に付いた実機では片脚が −1 のはず。**手で関節を動かし、D7 の読みの符号をシムの向きと照らし合わせる。**

## 手順

1. 機体を吊る。通電し、D7 コンソールで `scan 3`（10/10・`err=0`）。
2. 基準姿勢（脚をまっすぐ下・左右平行）で持ったまま `oa`（`YES ALL 10`）→ `scan 3` で全軸 `+0.0deg`。
3. 下の表の順に、**1軸だけ手でゆっくり 10〜20° 動かし、動かしたまま `scan 1`**。その軸の `pos` の符号を記録して基準姿勢に戻す。ほかの軸は動かさないように支える。
4. 10軸終わったら電源を切ってよい（原点は使い捨て）。

| # | 軸 | 手で動かす向き | シムでの符号（期待） | 実機の読み | 一致? |
|---|---|---|---|---|---|
| 1 | LL_HFE 0x21 | 左の腿を**前**へ上げる | **負** | | |
| 2 | LR_HFE 0x2A | 右の腿を**前**へ上げる | **負** | | |
| 3 | LL_KFE 0x1A | 左の膝を曲げる（足先を後ろへ） | **正** | | |
| 4 | LR_KFE 0x12 | 右の膝を曲げる（足先を後ろへ） | **正** | | |
| 5 | LL_FFE 0x2B | 左の爪先を**下げる** | **正** | | |
| 6 | LR_FFE 0x22 | 右の爪先を**下げる** | **正** | | |
| 7 | LL_HAA 0x11 | 左脚を**外**へ開く | **正** | | |
| 8 | LR_HAA 0x1B | 右脚を**外**へ開く | **正** | | |
| 9 | LL_HR 0x1C | 左の爪先を**外**へ向ける | **正** | | |
| 10 | LR_HR 0x13 | 右の爪先を**外**へ向ける | **正** | | |

「前」はロボットが `vx > 0` で進む向き（シムの +x）。どちらが前か分からなければ、それも書く。

## 判定

- **全軸一致** → 符号は正しい。前後に割れた原因は別（見え方・機構）。報告して止まる。
- **不一致の軸がある** → その軸の実機→H 符号を −1 にする。送信器は「目標角（H→実機）」と「観測（実機→H：位置・速度）」の**両方**で同じ符号を掛ける必要がある（片方だけだと方策が逆の世界を見る）。実装は次のチャットで、テストを付けてから。
- 予想: 1・3・5 か 2・4・6 のどちらか一方の組（片脚のピッチ3軸）が不一致。
