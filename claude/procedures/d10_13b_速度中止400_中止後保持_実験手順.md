# D10-13B: 速度中止を 400°/s にし、中止したら 3 s その場で保持してから力を抜く

> 作成 2026-09-23。根拠は `../reports/2026-09-23_d10-13_result.md`。
> 送信器 build **`D10_13B_SOFTSTOP_20260923_1900`**（`.bak_20260923_softstop` あり、テスト 165本 OK）。
> 異音・接触・支持ずれ・エラー・暴れたら、PC を操作する前に**主電源を切る**。**吊り紐は最後まで外さない。**

## なぜ

- D10-13 では、方策の段階が全 run で 0.2〜4.3 s で止まりました。どこかの軸が 190〜211°/s に達したところで、速度中止（200°/s）が働いたと推定しています。
- シムの方策は膝を約 250°/s（標準偏差）で動かします。200°/s は、この方策がふだん使う速さより低い値です。
- 中止のあとは全軸の力が抜けます。「膝から崩れ落ちた」のはこのためです。

## 何が変わったか

1. **`--walk-speed-abort-dps S`（`--walk-limits` 専用、200〜400、要承認）:** 速度中止を S°/s にします。付けなければ 200 のままです。
2. **`--soft-stop-seconds T`（`--walk-limits` 専用、0〜5 s）:**
   - 方策の段階で速度・電流・原点 45°の中止が起きたら、全軸を**止まった位置で** T 秒保持します。ゲインは STAND HOLD と同じです。そのあと、いつも通り力を抜きます（zero MIT）。
   - 画面に `ABORT in the policy stage: ...`、`SOFT STOP: ...`、`SOFT STOP complete` が出ます。
   - 保持中に通信が途切れる・モーターエラー・電流が表の値を超える、のどれかが起きたら、すぐに力を抜きます（`SOFT STOP ended early`）。
   - **T 秒のあいだに胴を受けてください。T 秒たつと力が抜けます。**
3. **中止の理由を `<CSV名>_abort.txt` に残します**（どの build の run でも）。`--analyze` が冒頭に `ABORT RECORD` として表示します。画面ログが無くても中止の理由が分かります。
4. 変えていないもの: 電流中止の表（KFE・FFE 10 A、HR 3 / HAA 6 / HFE 11 A）、slew ≤200°/s、stale、原点 45°、Kp/Kd、関節符号、duration ≤15 s。
