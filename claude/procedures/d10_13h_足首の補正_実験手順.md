# D10-13H: 同じ補正を膝ではなく足首へ（`--ankle-trim-deg 19 16`）

> 作成 2026-09-24。送信器 build **`D10_13H_ANKLETRIM_20260924`**（`.bak_20260924_ankletrim`、テスト 190本 OK）。支え方・禁止事項は D10-13E と同じ。

## D10-13G の結果（ログ）

| | D10-13D/E（補正なし） | D10-13G（膝の補正 19/16） |
|---|---|---|
| 床の保持で関節角が言う足裏（`SAGITTAL CHECK` と同じ計算） | −11〜−22°（中央値 −19 / −16） | **−3 / −2°**（pitch +12°でも +2°でも） |
| 方策が始まる直前の足首の電流 | 3〜5 A（ばねを縮めた状態） | **0.2〜0.4 A** |
| 0.5 s までの最大 pitch | 14.6〜25.4° | g1: 19.0°、**g1_2: 8.3°（これまでで最小）** |
| 終わり方 | — | g1: 0.50 s、LL_FFE が立ち姿勢 +45°。g1_2: 0.40 s、**LL_KFE がまっすぐより 12.3°逆に折れた**（歯止め 10°） |

- **補正で、関節角と T265 の食い違いは消えた。** 方策が思う姿勢と実物の姿勢が、初めて合った。
- ただし膝はまっすぐから 13 / 11°しか曲がっていない（本人所見「10°くらい」と一致）。**膝のエンコーダーは正しく、19°のずれは膝以外（足首か足裏）にある**と考えるのが自然。
- 方策はいつも最初に膝を 17〜26°伸ばすので、膝の余裕が 13°だと逆に折れて止まる（g1_2）。

## 何を変えるか

同じ 19 / 16°を、膝ではなく足首の読み替えに入れる（`--ankle-trim-deg 19 16`、`--knee-trim-deg` は使わない）。

- 床の上での姿勢の辻褄（`SAGITTAL CHECK` ≈ 0）は、膝の補正と同じになる（股・膝・足首の合計が同じだから）。
- 膝は D10-13D/E と同じ曲がり（まっすぐから 32 / 27°）に戻る。方策が膝を伸ばしても、逆には折れない。
- 空中では、足首が D10-13G よりつま先上げに見える。**床に降ろして足裏が平らになり、胴がまっすぐ立つかで判断する。**
- 起動時に `ANKLE TRIM: LL_FFE/LR_FFE offset now +28.4/+24.1` が出ることを確認する。
- 起動するときは、足首をだいたいまっすぐにしておく（足首が 45°以上ずれていると、起動時に拒否される）。
