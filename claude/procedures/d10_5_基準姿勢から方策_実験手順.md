## 何が変わったか

D10-4 は、全軸 0°（膝が伸びた姿勢）から方策の最初の出力へ ramp していた。これはシムが一度も見ていない姿勢で、方策は KFE +178° などを要求した。今回は `--stand-seconds` で次の順に動かす。

1. **stand-ramp**: いまの位置から**シムの初期姿勢**（HR 0 / HAA 0 / HFE −10° / KFE +20° / FFE −10°、左右同じ）へ `--ramp-seconds` かけて移す
2. **stand-hold**: その姿勢を `--stand-seconds` 保持し、**`HOLD POSE RESULT`（脚を開いた姿勢を重力に逆らって保つ電流）**を出す
3. **policy**: 前回行動ゼロ・送信目標は初期姿勢から、全軸 slew つきで方策へ

`--stand-only` を付けると 2 で終わる（方策なし）。プレアーム・ゲートは初期姿勢までの delta で判定する。

## 共通の事前条件（毎回）

1. 機体は床から完全に離して吊る。電源遮断担当が主電源に手を置く。
2. 通電後、D7 で `scan 3`。10/10・`err=0`・`age <= 0.3 s`。
3. **脚を基準姿勢（まっすぐ下・左右平行）に手で持ち、持ったまま `oa`（`YES ALL 10`）。そのまま `scan 3` で全軸 `+0.0deg` を確認する。** 脚を閉じた姿勢で `oa` しない（D10-4 はこれで HAA 原点が左約6°・右約12°ずれた）。
4. **run を起動するまで脚を持ち続ける。画面に最初の `RAMP progress: 0/10s` が出たら手を離す。** そこからはモーターが保持する。stand-hold と policy の間は触らない。
5. 冒頭の `ver9_d8_sender build=D10_5_STANDPOSE_20260923_1300` を確認。
6. CSV名は毎回変える（やり直しは `_a`→`_b`）。
7. 原点は1通電中に1回でよい。脚が閉じて次の run の開始位置がずれても、原点は打ち直さない（ゲートは「初期姿勢まで30°以内」しか見ない）。ただし電源を切ったら手順3からやり直す。

## 判定（走らせた後に基準を変えない）

| | 所見 | 意味 | 次 |
|---|---|---|---|
| **1** | R1 完走・全軸 headroom 正 | 初期姿勢を重力に逆らって保持できる。この表が床上中止値の根拠 | R2 へ |
| **2** | R1 が stand-ramp／hold で `current abort` | 脚を開いた姿勢の保持に上限以上が要る | 主電源OFF。**値を上げない。** 中止行と `AXIS SNAPSHOT` を報告 |
| **3** | R1 で脚が開かない／左右非対称 | 原点（`oa` の姿勢）か関節符号の問題 | 方策を回さない。`HOLD POSE RESULT` の droop と写真を報告 |
| **4** | R2 完走・足がぶつからない・`SLEW GAP` が D10-4 より小さい | 初期姿勢から始めると吊りでも方策が落ち着く | R3 へ |
| **5** | R2 完走だが `SLEW GAP` が D10-4 と同程度（KFE 100° 超） | 吊り（接地なし）そのものが分布の外。姿勢では直らない | R3 は1本だけ見て、床上手順（別に書く）へ進む判断材料にする |
| **6** | R2/R3 で `current abort` | 中止した軸と電流を報告 | **上限も slew も上げない** |
| **7** | R3 で左右交互に振れる | 歩容の形が出る | 床上の中止値を R1 表と R2/R3 実測から決め、**別手順を書いてから**床へ |
