# プロジェクト開始地点

Claude CodeとCodexの共通入口である。古い`README.md`、`project_handbook.md`、`next_chat_*`を最初から全読しない。履歴と重複が大きく、現在地の正本ではない。

1. リポジトリ直下で`git status --short`を実行し、既存変更を保護する。
2. `CONTEXT.md`で全体の現在地、正本、ローカル実行環境の位置を確認する。
3. `handoffs/ACTIVE.md`で今の優先作業・禁止事項・最小読書セットを確認する。
4. 作業の根拠になる報告書と数値の正本だけを読む。

| 種別 | 正本 | 更新するタイミング |
|---|---|---|
| 全体の現在地・入口 | `CONTEXT.md` | 優先作業、ブロック、成果物の場所が変わったとき |
| 次の担当への指示 | `handoffs/ACTIVE.md` | 作業の焦点または安全境界が変わったとき |
| 実験・調査の根拠 | `reports/YYYY-MM-DD_*.md` | 実測・調査・判断を完了したとき |
| 過去の会話経緯 | `chats/YYYY-MM-DD_*.md` | 必要な経緯を残すとき。開始点にはしない |

GitHub `main`は機械間の共有正本。`C:\Users\harut\Connect2USB2CAN`などの実行環境のCSV・重み・モデルはコミットせず、報告書に絶対パス、更新時刻、集計値を残す。
